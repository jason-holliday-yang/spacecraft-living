# SpaceCraft Living 世界地图本体重构方案（2026-04-30）

> 当前状态说明：本文档只讨论“世界地图本体”如何重构，不讨论 `M` 地图界面 UI 的版式，也不讨论剧情文本替换。它的目标是把现有世界从“可玩的任务区域平面图”推进到“更像大型开放世界游戏区域地图”的层级，让玩家即使不看 UI，也能从轮廓、地貌、地标和路径逻辑中读出这个地方为什么成立。

## 1. 文档目的

本文档要解决的问题不是：

- 地图上图例怎么摆
- `M` 界面的右侧信息栏要不要缩小
- 小地图描边和图标怎么换样式

本文档要解决的是：

1. 现有世界地图本体为什么看起来不像一个真实世界。
2. 如果要做得更像 `Cyberpunk 2077`、`GTA` 这类大型开放世界游戏里的“可被记住的地理空间”，应该优先改什么。
3. 当前代码里的北 / 东 / 西 / 南四向职责已经固定，如何在不推翻现有主线的前提下，把世界轮廓、区域过渡、空间地标和路线结构做得更成立。
4. 后续真正修改 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:49) 时，应按什么顺序施工，避免再次做成“任务分区拼图”。

一句话定位：

- `这是一份世界地图本体重构方案，不是 UI 改稿，也不是新增地图扩张计划。`

## 2. 使用范围

本方案只覆盖以下内容：

- 世界大轮廓
- 区域之间的自然过渡
- 主路线与侧路线的空间组织
- 中远距离地标体系
- 区域语义与剧情语义的统一
- 世界边界与不可达处理

本方案当前不覆盖：

- `M` 地图界面 UI
- 小地图配色和图标
- 资源点与怪物的具体数值平衡
- 日志文本和剧情扩写
- 新增地图区域

## 3. 当前问题总览

从当前实现看，世界地图本体最主要的问题有六类。

### 3.1 区域轮廓过于矩形化

当前北部遗迹、东部沼泽、南部设施都大量依赖矩形填充完成基础地形：

- 北部遗迹：见 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:105)
- 东部沼泽：见 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:113)
- 南部设施：见 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:121)

结果是：

- 玩家能读出“这里是一个区域”
- 但读不出“这里为什么会长成这样”

它更像几块不同功能的可玩区贴在一张平面上，而不是同一颗星球上互相影响的地貌。

### 3.2 区域过渡太硬

当前区域切换通常是直接换地块：

- 森林直接进入沼泽
- 自然区直接进入遗迹区
- 地表直接切入设施地带

这在功能上清楚，但在空间上显得很“系统化”。大型开放世界地图会让玩家先感到：

- 湿度在变化
- 地面在变硬或变碎
- 人工痕迹慢慢增加
- 危险先从边缘出现，再进入核心

当前这一层很弱。

### 3.3 路线结构太像任务章节切片

当前四个方向的职责是对的：

- 北线：终局执行
- 东线：风险学习
- 西线：人物调查
- 南线：设施真相

但地图本体给人的感觉仍然更像：

- 这一块是东线任务区
- 那一块是西线任务区
- 另一块是南线任务区

玩家容易形成“章节记忆”，而不是“地理记忆”。

### 3.4 中型地标不足

现在有终极地标：

- Signal Tower
- Monolith
- Northwest Ruins / Boss Arena

但缺少大量能够稳定支撑认路的中型地标，例如：

- 明显的断崖入口
- 大型坍塌带
- 可远望的设施骨架
- 水线分界
- 废墟边缘拱形结构
- 大面积树线断层

结果是玩家知道任务点在哪里，但不容易真的“记住路”。

### 3.5 世界边界过于“围栏化”

当前外圈很多地方通过树 / 石头规则重复地围出边界：

- 上下边界处理：见 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:129)
- 左右边界处理：见 [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:145)

这会产生明显的“游戏场地边框”感。

### 3.6 地图语义与剧情语义还没有完全咬合

剧情里已经在说：

- 这不是普通荒野
- 这是一颗被事故、设施、遗迹和生态失稳共同改写的星球
- 玩家是在逐步理解“世界本体结构”

但地图本体目前还是更像：

- 森林区
- 沼泽区
- 遗迹区
- 南部设施区

它更像玩法分类，还不完全像叙事分类。

## 4. 本轮重构目标

本轮世界地图本体重构的目标，不是把地图继续做大，而是把现有地图做得更“像地方”。

### 4.1 目标效果

重构完成后，玩家应当能获得以下直觉：

1. 不打开地图，也能感到自己正在从一个空间结构进入另一个空间结构。
2. 北 / 东 / 西 / 南四个方向不是四张任务表，而是同一世界里的四种不同地理命运。
3. 每个命名区域都有“为什么在这里”的原因。
4. 区域边缘、地表变化和中型地标能支持认路。
5. 地图看起来像一颗被历史和事故塑形过的星球，而不是若干矩形可玩区。

### 4.2 不追求的内容

本轮不追求：

- 再增加更多区域
- 新增更多系统
- 新增更多怪物类型
- 强行模仿现实世界城市布局

参考 `Cyberpunk 2077` / `GTA` 的重点不是“变成城市”，而是学习它们的世界原则：

- 大轮廓成立
- 路线有地理逻辑
- 地标层级明确
- 远看能认，近走能记

## 5. 世界结构重构原则

### 5.1 原则一：先做轮廓，再做内容

任何区域都必须先回答：

- 它的整体形状是什么
- 为什么是这个形状
- 它和相邻区域怎么咬合

如果先摆资源点、日志点、怪物点，再回头解释区域边界，最后很容易回到现在这种“任务区拼贴”的状态。

### 5.2 原则二：每个方向都要有地理逻辑

四个方向的功能可以不同，但必须都像地理结构，而不只是玩法结构。

- 北线应该像高处文明残留与执行区
- 东线应该像污染带逐渐加深的湿地系统
- 西线应该像事故后长期搜寻留下的人类活动带
- 南线应该像人工设施从地下反向顶回地表的塌陷区

### 5.3 原则三：世界过渡必须可读

每次进入一个新区域，玩家不应只通过颜色改变知道“换区了”，还应通过：

- 地面密度变化
- 障碍形态变化
- 可视距离变化
- 人工痕迹出现频率变化
- 水 / 雾 / 碎石 / 金属残骸的比例变化

来感知自己正在靠近什么。

### 5.4 原则四：中型地标优先于更多装饰

一百个散落的小石头，不如一个能被记住的断层边缘。

本轮应优先增加：

- 轮廓型地标
- 路径型地标
- 视线型地标

而不是先堆更多填充物。

### 5.5 原则五：边界要像自然极限，不像设计师说“不准过去”

玩家不应该感到“这里走不过去是因为地图结束了”，而应该感到“这里本来就不该能走过去”。

## 6. 分方向重构目标

### 6.1 基地与森林核心区

#### 当前问题

- 基地周边到森林的过渡还偏像“起点安全区”
- 世界中心感成立，但缺少“坠毁后临时生存核心”的痕迹扩散

#### 重构目标

- 基地外圈应像一片被多次往返踩出来的生存圈
- 森林不是纯教学草地，而是事故后的低风险回撤带
- 飞船附近应有更明显的“人为整理过”的空间

#### 需要增强的结构

- 飞船外围清理带
- 被频繁往返压出来的路径
- 少量坠毁外溢痕迹
- 安全区向未知区逐渐扩散的张力

### 6.2 北线：遗迹高地与终局执行带

#### 当前问题

- 遗迹体量足够大，但轮廓还是偏矩形平台
- 从自然区进入遗迹区的过渡缺少“爬升”和“文明侵入感”
- 终局区像一个功能舞台，但不够像真正占据高位的遗迹带

#### 重构目标

- 北线要像整张地图里最“高位、古老、仪式性”的区域
- 不是一块大灰地，而是一整片逐级进入的上层结构
- 玩家应能从外围就感觉到“这里是世界的上缘”

#### 结构调整建议

- 把遗迹外缘做成不规则侵入边界，而不是几层整齐平台
- 增加“上行感”：狭窄入口、视线豁然打开、石构越来越密
- Monolith Ring 应更像秩序区，不只是战斗前庭
- Signal Tower Plateau 应更像整个北线的视线终点，而不是单独一个任务点

#### 关键词

- 上缘
- 石构秩序
- 高位执行
- 文明残留压住自然

### 6.3 东线：湿地污染与深区资格带

#### 当前问题

- 外沼、深沼和深盆地分层明确，但视觉上还是几个矩形块串起来
- 深入过程是功能成立的，但“湿地系统”的自然感不足
- 东线的可怕更多来自数值和状态，而不是地形自身讲故事

#### 重构目标

- 东线要像一个逐渐加深、逐渐吞没地表的湿地污染系统
- 玩家能感到自己不是“进入下一个关卡”，而是在向环境更糟的低处推进

#### 结构调整建议

- 外沼边缘用零散侵蚀感代替硬切地块
- Flooded Detour 应像被水线和软地撕开的路径，不像纯粹绕路走廊
- Deep Gate 应像湿地与深区的天然分界，不只是一个门槛点
- Deep Basin 应有明显“盆地感”，让玩家意识到自己是在往一个更低、更难撤的地方走

#### 关键词

- 下沉
- 浸泡
- 污染加深
- 风险提交

### 6.4 西线：搜寻活动带与回声地貌

#### 当前问题

- 西线功能上已经是调查线，但地图容易读成左侧条带
- 区域之间更像依次排列，而不像同一片广阔搜寻带中的不同层次
- Echo Basin 和 Last Camp 的“终点感”还不够强

#### 重构目标

- 西线应像最能体现“人类曾经反复搜寻、撤退、留下痕迹”的区域
- 它要有空间纵深，也要有情绪纵深

#### 结构调整建议

- West Frontier 不只是入口，应像正式搜寻边界
- Survey Break 应像第一次真正分叉和失联的现场
- Canopy Hollow 应像视线复杂、判断成本高的中段调查区
- Echo Basin 必须成为西线最有空间感的一块大盆地
- Last Camp 应是最安静、最完整、最像“有人认真停下来做决定”的地方

#### 关键词

- 搜寻痕迹
- 回声
- 空旷与安静
- 人类选择的残留

### 6.5 南线：设施回返与地下系统外翻带

#### 当前问题

- 南线目前最像“底边拼接设施块”
- 虽然已经有阶段链条，但塌陷、层级、控制逻辑还不够强
- 玩家知道这是设施线，但还不够强地感到“世界正在从地下翻出来”

#### 重构目标

- 南线要像整张图里最具“人工系统反向暴露”感的区域
- 玩家应感觉自己是在深入一台被地层埋住又重新露出的机器

#### 结构调整建议

- South Collapse 应更像巨大前厅和坍塌入口
- Vent Galleries 应体现“风管 / 通气 / 输送”的方向性
- Service Shafts 应有更强骨架感，像一整片垂直组织
- Purifier Ring 必须像核心设施，不只是另一个灰色块
- Root Vault 必须像最深处的收束核心，而不是地图底角一个终点点位

#### 关键词

- 外翻
- 设施骨架
- 机器内部
- 深处收束

## 7. 过渡带设计要求

本轮重构必须显式加入过渡带思维。

### 7.1 森林 -> 东线湿地

要有：

- 土地变软
- 植被变稀
- 湿痕 / 水痕增加
- 可撤回路线还清楚，但越来越不舒服

### 7.2 森林 -> 北线遗迹

要有：

- 石构碎片开始出现
- 树线被人工边缘打断
- 地势与可见度改变
- 玩家感觉在接近高处秩序区

### 7.3 森林 -> 西线搜寻带

要有：

- 搜索痕迹
- 临时标记
- 路线试探失败的遗留物
- 人类活动感比自然突变更强

### 7.4 森林 -> 南线设施塌陷带

要有：

- 破裂地表
- 金属 / 管线 / 结构外露
- 地面逐渐失去天然感
- 不是直接切入“室内”，而是先经历“地表被设施改写”

## 8. 地标体系重构

地图要能被记住，必须建立三层地标。

### 8.1 一级地标：全图级

这些地标负责远距离定位：

- 飞船基地
- Signal Tower
- Northwest Ruins
- 东线深盆地核心轮廓
- 南线主设施骨架

### 8.2 二级地标：区域级

这些地标负责进入区域后快速确认位置：

- Ruins Approach 石构断边
- Flooded Detour 水线裂口
- Survey Break 勘测残骸区
- Echo Basin 盆地边缘
- South Collapse 坍塌前厅
- Purifier Ring 外圈结构

### 8.3 三级地标：路径级

这些地标负责局部认路：

- 明显的树线断口
- 单侧巨石 / 残骸带
- 小型拱门 / 管线出口
- 可回头识别的断桥、坡口、石柱

## 9. 世界边界重构原则

### 9.1 当前问题

当前世界边界有较强规则重复感，容易读成游戏场地边框。

### 9.2 目标

边界应表现为：

- 不可通行的自然极限
- 危险环境的逻辑终点
- 世界并未结束，但当前角色没法穿过去

### 9.3 处理方式

应更多使用：

- 大轮廓阻隔
- 斜向压迫
- 地势缺口
- 连续危险带

应减少：

- 等距排布的树和石头
- 明显的“围墙线”
- 为了挡路而挡路的重复物件

## 10. 代码层执行顺序

真正施工时，必须按下面顺序推进。

### 10.1 第一阶段：只改大轮廓

目标：

- 先重画北 / 东 / 西 / 南的宏观边界
- 不急着摆资源点和战斗点

代码重心：

- [map_layout_world.c](/Users/jason/Documents/SpaceCraftLivng/src/map_layout_world.c:49)

完成标准：

- 不看标签，不看 UI，也能一眼区分四个方向的地理性格

### 10.2 第二阶段：加入过渡带

目标：

- 修掉“硬切区”的观感

完成标准：

- 玩家从一个方向进入另一个方向时，会先经历变化，而不是瞬间换皮

### 10.3 第三阶段：补中型地标

目标：

- 让玩家开始形成空间记忆

完成标准：

- 玩家能用“那个坍塌边缘”“那个大盆地口”“那条风井骨架”来描述自己在哪里

### 10.4 第四阶段：重排路径细节与阻挡物

目标：

- 让路径既服务玩法，也服务世界合理性

完成标准：

- 路为什么这么走，有地理上的解释

### 10.5 第五阶段：最后再校资源点 / 日志点 / 怪物点

目标：

- 让内容落在已经成立的空间里

完成标准：

- 内容像是长在世界上，不像被摆进世界里

## 11. 验收标准

世界地图本体重构完成后，至少要满足下面这些检查项。

### 11.1 轮廓检查

- 北 / 东 / 西 / 南四向不能再主要依靠大矩形读出来
- 每个大区从缩略视角看都要有独立轮廓性格

### 11.2 路线检查

- 玩家能说清每个方向为什么那样延伸
- 路线是地理上的推进，不只是任务上的推进

### 11.3 记忆检查

- 玩家第一次走完后，能记住至少一个全图地标、两个区域地标、三个路径地标

### 11.4 叙事检查

- 看地图本体就能感到：
  - 北线是高位执行区
  - 东线是下沉湿地区
  - 西线是搜寻活动带
  - 南线是设施外翻带

### 11.5 边界检查

- 玩家不会立刻意识到“这里是地图边界”
- 不可通行的地方有世界内理由

## 12. 本轮建议结论

如果接下来真的开始动世界地图本体，优先级应固定为：

1. 先改大轮廓
2. 再改过渡带
3. 再补中型地标
4. 最后才调整细节装饰和内容点位

不要反过来。

如果反过来做，结果很可能只是：

- 区域里东西更多了
- 地图仍然还是那张任务区拼图

本方案的最终目标不是“让地图更复杂”，而是：

- `让这张世界地图终于像一个真实存在、能被玩家记住、能承载剧情重量的地方。`
