# SpaceCraft Living 地图-剧情联动补齐执行单（2026-04-10）

## 1. 文档目的

本文档用于把“当前地图做完整，并让当前剧情和当前地图彻底联动起来”这件事拆成可以直接执行的补齐清单。

它允许在当前既定世界框架内补齐西线与南线，但不讨论超出这两条线之外的新地图扩张，也不讨论另一套独立主线。

它只回答下面这些问题：

- 当前固定地图中，每个区域到底承担什么剧情职责
- 玩家为什么在当前阶段去这个方向
- 玩家在这个区域应该知道什么
- 玩家回到基地之后，主线状态应该怎样变化
- 什么样的补齐属于“完成当前地图”，而不属于“继续扩展内容”

## 2. 当前统一范围

从当前这轮开始，地图和剧情联动补齐必须遵守以下范围约束：

- `现有世界布局主框架已经定版`
- `当前允许并要求补齐西线 Echo Wilds 与南线 Subsurface Sink`
- `在补齐西线 / 南线后，不再继续扩展更大的新地图、新剧情主线或大型新玩法系统`
- `地图补齐的目标是让当前世界完整，而不是无限继续把世界做大`
- `剧情补齐的目标是让现有主线、西线和南线形成完整闭环`

换句话说：

- 当前要做的是 `完成现有地图`
- 包括把西线 / 南线从占位区补成正式可玩内容

## 3. 地图-剧情联动总原则

每个关键区域都必须同时回答 3 个问题：

1. `进入理由`
   玩家为什么现在要来这里
2. `信息收获`
   玩家在这里知道了什么
3. `返回结果`
   玩家回到基地后，主线到底推进了什么

如果一个区域只承担采集、战斗或地形阻挡，而不能回答这 3 个问题，那么它的地图-剧情联动仍不完整。

## 4. 当前固定世界结构

当前世界应固定理解为下面这套结构：

- `飞船基地`
  剧情中枢、恢复点、制作点、路线确认点
- `森林`
  开局认知区与低风险教学区
- `东侧 swamp`
  风险学习区、状态处理区、路线规划区
- `北侧 ruins`
  真相回收区、终局准备区、终局执行区
- `西侧 Echo Wilds`
  船员调查区、潜行追踪区、定居动机补强区
- `南侧 Subsurface Sink`
  设施控制区、真相揭示区、终局准备补强区

当前这张地图不是平均展开的大平面，而是固定形成：

- `基地 = 准备中心`
- `东线 = 资格考试`
- `西线 = 人与选择`
- `南线 = 系统与真相`
- `北线 = 最终执行`

## 5. 分区联动补齐

### 5.1 飞船基地：剧情中枢

当前应固定承担：

- 完整恢复
- 主线解释
- 路线确认
- 终局确认

当前已经成立的基础：

- 基地已经承担完整恢复点职责
- Loxi 终端已经承担目标同步与路线解锁职责
- 工作台、氧气舱、终端舱、诊断舱已经开始有明确功能分工

仍需补齐的内容：

- `阶段开始反馈`
  每次新阶段开始时，基地必须给出一句明确的剧情判断，而不只是切换 objective。
- `外出返回总结`
  每次玩家从东线或北线回来，都要让基地给出“你刚刚确认了什么、下一步为什么要去哪”的总结。
- `舱室叙事身份固定`
  每个主要舱室除了功能，还要承担剧情职责。
- `飞船状态变化感`
  氧气修复、能源修复、终局解锁后，基地文本与反馈应明确变化。

完成标准：

- 玩家每次回基地，都能感到“剧情在这里被解释和确认”
- 基地不再只是回血点，而是完整主线中枢

### 5.2 森林：开局认知区

当前应固定承担：

- 低风险探索教学
- 第一次外出回撤循环
- 初始材料与夜间认知建立

仍需补齐的内容：

- `基础循环说明更完整`
  森林必须把“出去一小段 -> 带资源回来 -> 再出门”这件事教清楚。
- `夜间与潜行认知更稳定`
  Glow Stick 与 crouch 的价值应继续通过文本和区域反馈巩固。
- `和基地的闭环更明确`
  玩家第一次回基地后，应更明显感到“飞船是恢复和判断中心”。

完成标准：

- 森林不再只是前期资源草地，而是完整的开局认知空间

### 5.3 东侧 swamp：风险与准备教学区

东线当前不是单纯资源区，而应固定承担：

- 风险学习
- 状态处理
- 补给规划
- 深区资格建立

#### Outer Swamp Rim

当前剧情职责：

- 第一次明确告诉玩家：危险不仅来自怪物，也来自环境与路线长度

仍需补齐：

- 首次到达时更明确的 Loxi 判断
- 通讯修复与“必须先恢复外部联系”之间的叙事绑定
- 强化它是教学线，而不是深区主体

完成标准：

- 玩家知道自己正在学“外出成本”而不是单纯刷材料

#### Flooded Detour

当前剧情职责：

- 把“路线本身就是代价”讲清楚

仍需补齐：

- 更明确地把 Rope 与 Field Camp 绑定到回程稳定性
- 让这里承担“第一次真正规划中途回撤”的叙事意义
- 避免玩家把它误解成普通延长路段

完成标准：

- 玩家理解这里是在学习路线规划，而不是在无意义绕远

#### Deep Gate

当前剧情职责：

- 东线最后低承诺回撤点

仍需补齐：

- 明确告诉玩家：再往里不是普通探索，而是提交风险
- 强化这里是“可以整理后撤、再做下一轮推进”的节点
- 让 Deep Gate 成为真正可读的阶段分界线

完成标准：

- 玩家能一眼读出“这里是最后一次容易回头的地方”

#### Deep Basin

当前剧情职责：

- 东线高压验证区
- 关键推进资源回收区

仍需补齐：

- 强化 `Energy Core` 的剧情推进身份，而不只是资源身份
- 强化“为什么能源修复是北线前置条件”的叙事结果
- 玩家回基地后，应明显感到“东线这一轮任务已经完成了自己的使命”

完成标准：

- 东线形成完整闭环：
  `学风险 -> 学回撤 -> 学资格 -> 带成果回基地`

### 5.4 北侧 ruins：真相与终局执行区

北线当前应固定承担：

- 真相回收
- 终局准备
- 路线选择
- 终局执行

#### Ruins Approach

当前剧情职责：

- 终局前厅

仍需补齐：

- 更明确地告诉玩家：这里已经进入终局空间，但还没有到最终承诺点
- 让碎片收集更像“终局准备”而不是“普通收集任务”
- 让玩家感到这里仍然允许回头整理

完成标准：

- 玩家知道 `Ruins Approach` 是准备段，不是最终执行段

#### Monolith Ring

当前剧情职责：

- 真相解释区
- 准备转折区

仍需补齐：

- 石碑不只承担 buff 功能，也要承担解释功能
- 每次点亮石碑，都应更清楚地解释：
  - Boss 为什么会变弱
  - Signal Tower 为什么会更稳定
  - 遗迹系统和终局三路线到底是什么关系
- 这里应成为“剧情理解最完整”的区域

完成标准：

- 玩家把 Monolith Ring 读成“终局理解区”，不是中间关卡

#### Signal Tower Plateau

当前剧情职责：

- 最终执行区

仍需补齐：

- 英雄路线、和平路线、定居路线的空间意义必须在这里彻底分开
- 让玩家感到自己是在主动执行路线，而不是误触发结局
- 如果玩家最终选择定居，也应让人感到这是“看过离开可能之后的主动放弃”

完成标准：

- 玩家进入塔区时，能明确知道自己现在在做哪一种终局执行

### 5.5 西侧 Echo Wilds：调查与人物线

西线当前应固定承担：

- 失踪船员调查
- 中后期潜行与追踪
- 对“留下还是离开”的情感补强
- 对定居路线与和平路线的主题反哺

#### West Frontier

当前剧情职责：

- 西线入口与调查动机建立点

仍需补齐：

- 把“封锁边界”升级成“可进入的搜寻前沿”
- 用第一批残骸、短报文和痕迹建立调查动机
- 让玩家明确知道西线不是资源线，而是人物与去向线

#### Survey Break / Canopy Hollow / Echo Basin / Last Camp

当前剧情职责：

- 分别承担追踪、潜行、定位与情感收束

仍需补齐：

- `Survey Break`
  用断裂勘测线与调查节点建立追踪链

  用低视距和观察营地建立西线中段身份
- `Echo Basin`
  用回声与高点观察把线索收束为结论
- `Last Camp`
  给出第一轮明确的人物答案与选择证据

完成标准：

- 玩家会把西线读成“调查谁留下了什么、为什么有人选择不回去”的可玩剧情线

### 5.6 南侧 Subsurface Sink：设施与真相线

南线当前应固定承担：

- 地下设施调查
- 环境控制与风险改写
- 事故与遗迹系统真相揭示
- 对和平路线与英雄路线的终局准备补强

#### South Collapse

当前剧情职责：

- 南线入口与设施感建立点

仍需补齐：

- 用半埋设施、弱电力回响和塌陷结构建立南线动机
- 让玩家明确知道南线是系统线，不是单纯地下地图

#### Vent Galleries / Service Shafts / Purifier Ring / Root Vault

当前剧情职责：

- 分别承担节点控制、纵向路网、环境改写与真相收束

仍需补齐：

  建立通风 / 供氧节点控制的第一轮玩法
- `Service Shafts`
  建立纵向路网、捷径与维修回路

完成标准：

- 玩家会把南线读成“接管系统、改写环境并理解事故真相”的可玩剧情线

## 6. 跨区域联动要求

除了区域内补齐，还必须满足下面这些全局规则：

### 6.1 每次阶段推进都要改变玩家对地图的理解

例如：

- `Stage 3`
  东线从“外部探索”变成“通讯修复方向”
- `Stage 5`
  东线从“外层教学”变成“深区资格验证”
- `Stage 4 - Stage 6`
  西线从“可疑方向”变成“人物调查与选择理解线”
- `Stage 5 - Stage 7`
  南线从“封锁塌陷区”变成“设施控制与真相揭示线”
- `Stage 6`
  北线从“危险遗迹”变成“终局准备路”
- `Stage 7`
  北线从“准备路”变成“路线执行路”

### 6.2 每个关键地图节点都要承担故事功能

当前关键节点至少应满足下面的叙事身份：

- `Comm Relay`
  恢复外部联系
- `Crash Clue`
  把主线从求生推进到调查
- `Energy Console`
  把东线成果转成北线资格
- `Monolith`
  把准备转成终局优势
- `Signal Tower`
  把路线选择转成最终结果

### 6.3 返回基地必须形成叙事闭环

必须形成下面这种循环：

- 去某个区域有明确理由
- 在区域内知道了新的事情
- 回基地后，Loxi 或系统给出明确总结
- 下一次外出因此变得更有方向

### 6.4 地图 UI 与剧情解释必须统一

下面这些内容必须说同一件事：

- objective
- communicator
- field note
- map overlay
- minimap 命名
- objective marker

不能出现：

- 地图把西线 / 南线写成正式可玩区
- 文本却又还把它们说成“未来可能开启的边界”

## 7. 地图补齐不等于地图扩张

当前“地图做完整”的正确含义是：

- 把现有区域职责补清楚
- 把现有路线读感补清楚
- 把西线 / 南线补成完整任务链
- 把现有剧情嵌进现有地图

它不等于：

- 在西线 / 南线之外继续增加新的大区域
- 再开超出当前目标的地图扩展设计
- 再新增另一套独立主线总纲
- 为了内容更多而继续无边界加面积

## 8. 推荐执行顺序

建议按下面顺序推进：

1. `基地 -> 东线 -> 基地`
   先补前中期闭环，让玩家每一轮外出都有剧情结果。
2. `基地 -> 西线 -> 基地`
   再补人物调查与定居主题，让西线形成独立闭环。
3. `基地 -> 南线 -> 基地`
   再补设施控制与真相线，让南线形成独立闭环。
4. `基地 -> 北线 -> 终局选择`
   最后补终局闭环，让北线回收前面所有准备收益。

## 9. 当前完成判断

当下面这些条件同时满足时，可以认为当前地图-剧情联动补齐基本完成：

1. 玩家在每个主区域都能回答“为什么现在来这里”
2. 玩家在每个关键区域都能获得明确的信息收获
3. 每次关键返回基地后，都有清楚的剧情状态变化
4. 东线被读成风险与准备教学区，而不是单纯资源区
5. 北线被读成真相与终局执行区，而不是单纯高难区
6. 西线与南线被读成完整可玩区域，而不是缺失地图块或纯占位边界
7. objective、communicator、map overlay 和 marker 的口径彼此一致

## 10. 第一批实际修改顺序表

这一节不再停留在原则层，而是给出第一轮最适合直接动手的修改顺序。

当前建议坚持一条规则：

- `先改文本与反馈`
- `再改交互与状态变化`
- `最后再补视觉与装饰`

原因：

- 文本和反馈最先决定玩家是否读懂地图职责
- 交互和状态变化决定地图与剧情是否真正闭环
- 视觉和装饰应该建立在职责已经明确之后
