## 1. 文档目的

本文档用于把“游戏已经完整可玩，但还需要继续打磨平衡性”这件事拆成可执行的开发任务。

当前需要先统一一个前提：

- `当前会先完成西线 / 南线补完，再冻结地图、剧情和玩法设计范围`
- `本文件已经成为当前主开发计划之一`
- `后续工作不再以扩展内容为目标，而只围绕平衡、稳定性和护栏收尾`

## 2. 当前平衡性总判断

当前版本的平衡方向整体是成立的：

- 游戏主要依靠 `血量 + 氧气 + 状态` 的组合消耗制造压力
- 装备、营地和消耗品已经能显著改变路线稳定性
- 玩家死亡更偏向“准备和撤退判断失误”，而不是单次瞬杀

但当前仍不能说平衡已经收尾。

更准确地说：

- `整体方向是对的`
- `局部曲线还不够透明`
- `少数关键经济与战斗节点还缺显式护栏`

当前最值得优先关注的三个问题是：

1. `资源刷新规则已经存在，但调参逻辑偏隐性`
2. `和平路线的终局资源预算仍有隐藏成本`
3. `中后期战斗的 TTK 跳变较大，仍需收口到更稳定的目标带`

## 3. 资源经济审查

### 3.1 当前资源刷新结构

当前资源刷新规则主要由 `src/task_survival.c` 控制：

- 玩家离开节点所属 `area` 才会累计刷新时间
- 高产节点刷新阈值约 `95s`
- 低产节点刷新阈值约 `135s`
- `special` 节点刷新阈值约 `240s`
- 每个节点都有 `respawnsRemaining` 上限

当前开发阶段新增的强约束（必须满足）：

- `飞船内资源节点` 只允许拾取一遍，不参与循环刷新。
- `飞船外资源节点` 才进入刷新体系，并继续遵守 `awayTimer + area` 语义。
- `Stage 1 - Stage 2` 主线关键资源必须有保底供给，不能因刷新或分布问题导致主线硬锁。
- 关键示例：`Ore` 不能出现“飞船内未刷新 / 无可采集节点”导致 `Stage 1` 无法推进的情况。
- 玩家侧刷新提示只允许显示抽象状态（如 `可采集 / 枯竭中 / 已恢复`），不直接暴露底层计时阈值与剩余次数。

这套规则的优点是：

- 能避免玩家站桩原地刷资源
- 能让“回撤 -> 再出门”成为经济循环的一部分

但当前的主要风险是：

- 刷新逻辑对玩家不可见，体感容易被理解成“有时会刷、有时不会刷”
- 刷新按 `area` 而不是按距离计算，会让某些长线探索区在同一区域内持续枯竭
- 当前还没有专门保护刷新阈值与刷新方式的 smoke 测试
- 当前尚缺“主线防硬锁”的资源保底护栏（尤其是前两阶段基础建材）

### 3.2 当前关键资源底盘

基于当前节点配置，核心资源底盘大致如下：

| 资源 | 基础节点数 | 基础总产出 | 理论总产出上限 |
| --- | --- | --- | --- |
| `Wood` | `10` | `20` | `100` |
| `Metal Scrap` | `3` | `5` | `24` |
| `Ore` | `4` | `4` | `16` |
| `Glow Moss` | `5` | `7` | `35` |
| `Alien Vine` | `3` | `6` | `24` |
| `Protective Fiber` | `2` | `2` | `6` |
| `Energy Crystal` | `2` | `2` | `6` |
| `Relic Fragment` | `3` | `3` | `9` |

从总体上看：

- 前中期基础制作资源并不紧缺
- 真正的关键预算集中在 `Energy Core / Energy Crystal / Relic Fragment / Protective Fiber`
- 因此后续调平衡时，应优先盯关键路径资源，而不是先动 `Wood / Fruit` 这类基础材料

### 3.3 当前配方与主线资源预算

当前主线路径的资源压力并不主要来自基础材料，而主要来自终局准备。

明显成立的结论：

- `Glow Stick / Rope / Laser Gun / Protection Suit / Field Camp` 的成本整体还在可控范围内
- `Energy Core + Energy Crystal + Relic Fragment` 才是终局路线真正的预算敏感点

当前最值得关注的经济问题是：

- `Stage 6` 终端同步会直接消耗 `3 Relic Fragments`
- `Signal Amplifier` 配方又额外要求 `1 Energy Core + 3 Relic Fragments`

这意味着：

- 和平路线当前的真实碎片预算，不是表面上第一次看到的 `3`
- 它更接近“终端解锁一轮 + 制作一轮”的双层预算

这并不一定是错误，但它目前存在两个明显问题：

- 玩家很容易先从文本上理解成“只需要 3 个碎片”
- 当前文档和测试还没有把这件事作为一个明确的经济护栏写清楚

### 3.4 当前资源经济最值得优先修的地方

优先级建议：

1. 先明确 `Relic Fragment` 和 `Energy Core` 的终局预算口径
2. 再决定刷新阈值是否要继续保留当前的 `95 / 135 / 240` 结构
3. 最后再微调常规材料产量

原因：

- 终局关键材料比基础材料更容易直接影响“路线是否可理解”
- 玩家能接受难拿，但很难接受“实际预算和文案理解不一致”

额外硬约束：

- 在终局预算之外，必须先保证“前期关键资源永不缺席”。
- 前期资源不足属于 `P0` 阻断问题，优先级高于中后期数值细调。

## 4. 战斗平衡审查

### 4.1 当前玩家攻击基线

当前玩家攻击基线大致如下：

- 近战基础伤害约 `16`
- 激光枪基础伤害约 `28`
- 激光枪攻击额外带来 `5 格直线攻击范围`
- 攻击还会消耗氧气，近战约 `2.2`，激光约 `3.2`

这套结构本身是合理的：

- 激光枪不仅更强，还更安全
- 攻击不是白送动作，而是要付出氧气成本

### 4.2 当前怪物血量带

当前怪物血量大致落在下面这组带里：

| 敌人 | 当前血量 |
| --- | --- |
| `Thorn Larva` | `28` |
| `Wing Bug` | `18` |
| `Raptor` | `52` |
| `Swamp Stalker` | `48` |
| `Sentinel Jelly` | `72` |
| `Fog Worm` | `64` |
| `Relic Guard` | `92` |
| `Final Boss` | `220` |

由此带来的当前 TTK 读感大致是：

- 前期怪几乎都是 `1-2` 次激光或 `2` 次近战
- 中期怪大多是 `2-3` 次激光或 `3-5` 次近战
- 遗迹守卫要 `3-4` 次激光或 `5-6` 次近战
- Boss 会因为背后判定与石碑增伤而出现较大的击杀轮次差异

### 4.3 当前战斗体验的主要风险

#### 风险 A：激光枪的体验跳变偏陡

当前激光枪一旦到手：

- 早中期很多怪会直接降到 `1-2` 个攻击回合
- 玩家主观体验会从“战斗需要谨慎”快速跳到“战斗突然很稳”

这可能是有意设计，但目前仍需要明确：

- 这是“刻意的阶段奖励”
- 还是“数值跳变过大但暂未收口”

#### 风险 B：Boss TTK 的上下限拉得较开

当前 Boss 既吃：

- 背后位置 `x2`
- 石碑点亮每层 `+10%`

这会导致：

- 不熟练玩家正面硬打时，Boss 很像高血量拖时战
- 熟练玩家从背后 + 点亮石碑后，Boss 又会显得明显更脆

这种“准备收益显著”本身没问题。

但当前仍需要先明确一个开发目标：

- Boss 被充分准备后，应该快到什么程度才算合理
- Boss 在最低合格准备下，应该慢到什么程度还不会拖垮体验

#### 风险 C：怪物危险主要来自状态叠加，但缺少显式目标带

当前怪物对玩家的危险结构更偏向：

- 低到中等直伤
- 中到高的 `poison / oxygen leak / oxygen loss`

这个方向和设计文档是一致的。

但当前还缺一组明确护栏，例如：

- 中期怪应以几次接触把玩家逼入撤退窗口
- 深区怪应在什么准备下仍然危险但可逆
- 保护服和消耗品应把风险削到什么程度才算“体感明显”

### 4.4 固定区域布怪原则

当前收尾阶段的布怪原则已经固定，不再继续增加常规怪数量：

- 常规怪固定只分布在 `西线 + 南线`
- `东线 swamp` 不再额外布置常规怪，平衡重点应转向环境伤害、耗氧、补给与回撤窗口
- `北线 ruins` 只保留 `Monolith Ring` 守护者；最终 Boss 单独归属英雄路线隐藏战区

在固定数量下，推荐威胁点分布为：

- 西线：`West Frontier`、`Canopy Hollow`、`Echo Basin`
- 南线：`South Collapse`、`Service Shafts`、`Root Vault`

其余区域 `Survey Break`、`Last Camp`、`Vent Galleries`、`Purifier Ring` 应保留为以调查、日志回收和路线辨识为主的低战斗段。

## 5. 当前测试与文档缺口

当前已经有不少 smoke 测试保护生存系统与终局流程，但平衡性本身还缺几类专门护栏：

### 5.1 资源刷新缺口

当前缺少专门测试去保护：

- 节点刷新阈值
- 离区刷新逻辑
- `special` 节点较慢刷新的语义
- 飞船内节点“单次拾取、不刷新”的固定规则
- 飞船外节点“可刷新且有上限”的固定规则
- `Stage 1 - Stage 2` 关键资源（至少 `Ore`）的主线可达性保底

### 5.2 关键经济缺口

当前缺少专门测试去保护：

- 主线关键配方预算是否足够
- 和平路线 `Relic Fragment / Energy Core` 预算是否清晰
- 关键资源点在最低合格路线下是否足够支撑一次通关

### 5.3 战斗曲线缺口

当前缺少专门测试去保护：

- 典型怪物的目标 TTK 区间
- 保护服、营地、石碑、日志奖励对战斗稳定性的收益幅度
- Boss 在“无石碑 / 满石碑 / 和平路线准备”三种条件下的差异带

## 6. 推荐的调优顺序

建议按下面顺序推进：

1. 先补测试与文档护栏
2. 再明确终局资源预算
3. 再收口 Boss 与中后期怪的 TTK 目标带
4. 最后再微调常规节点刷新和普通材料数量

## 7. 剧情玩法平衡建议

当前剧情主线的骨架本身没有问题，问题主要集中在“阶段职责已经成立，但少数门槛说明和收益反馈还不够对称”。

### 7.1 Stage 1 - Stage 2：前期教学应继续保持轻量直线

当前判断：

- 前两阶段已经能自然建立 `基地恢复 -> 森林采集 -> 氧气修复 -> 回撤再出门` 的基础闭环
- `Glow Stick` 的解锁时机也合理，能把“夜间信息劣势”做成第一次真实准备收益

建议：

- 不再提高前两阶段材料成本
- 保持 `氧气修复` 带来的明确正反馈，不把前期难度继续堆到数值上
- 前两阶段只负责建立“外出有成本、回撤有价值”，不提前塞入复杂状态管理
- 前两阶段关键材料（`Wood / Metal Scrap / Ore`）必须保证“至少一轮主线所需可稳定获取”
- 飞船内资源可作为教学保底，但必须一次性拾取，不得被当作循环资源池

### 7.2 Stage 3 - Stage 5：东线应始终承担“准备换推进”的教学职责

当前判断：

- `Stage 3` 已把外部探索第一次明确推到东侧
- `Stage 4` 用 `Laser Gun + Protection Suit` 建立了资格门槛
- `Stage 5` 再用 `Energy Core` 把玩家送入深沼核心，整体结构是合理的

当前最需要收口的点：

- `Stage 3` 与 `Stage 4` 的推进提示已经较清楚，但玩家很容易把东线误读成“只要战斗够强就能硬顶”
- 实际上当前代码更鼓励 `Rope + Field Camp + Protection Suit + 补氧 / 解毒资源` 的完整准备链
- 这意味着东线最该强调的是 `路线规划收益`，而不是单纯战斗收益

建议：

- Stage 3 文案继续强调 `Outer Swamp Rim` 只是教学线，不鼓励无准备深入
- Stage 4 文案把 `Protection Suit` 的地位抬高到与 `Laser Gun` 同级，避免玩家误判为“先有枪就够了”
- Stage 5 应继续明确：`Deep Gate` 是最后的低承诺回撤点，`Deep Basin` 才是真正的高压验证区
- 后续调参优先调整 `东线路线压力组合`，不要单独只调怪物伤害

### 7.3 Stage 6 - Stage 7：终局预算必须更透明

当前判断：

- 北线已经形成 `Ruins Approach -> Monolith Ring -> Signal Tower Plateau` 的三段结构
- 英雄路线与和平路线的玩法差异也已经成立
- 但和平路线当前存在明显的“实际预算大于表面理解”的问题

当前代码对应的真实预算是：

- `Stage 6` 终端同步需要先交 `3 Relic Fragments`
- `Signal Amplifier` 又需要 `1 Energy Core + 3 Relic Fragments`

这意味着和平路线的真实门槛不是“拿到 3 个碎片”，而更接近：

- `6 Relic Fragments + 1 Energy Core`

建议：

- 必须把这个预算差异明确写进任务提示、通讯器提示和配方说明
- 如果不想改资源数量，至少要改文案，避免玩家误解成被二次收费
- 如果后续想继续压低和平路线挫败感，最先考虑的应是 `Signal Amplifier` 的碎片成本，而不是直接削平 Boss

### 7.4 终局三路线应维持清晰分工

建议继续坚持下面的路线定义：

- `英雄路线`：高风险、高压、强调石碑准备、guardian 击杀窗口与回船后的主动确认
- `和平路线`：高准备、低战斗、强调信号增幅器、稳定氧气计划与回船后的主动确认
- `定居路线`：低冲突、重确认、强调“你主动放弃求救而不是误触发”，且必须在洛希分支点完成二次确认
- 三条路线都应先经过 `飞船 / 洛希分支点`，再进入各自的最终执行段；Signal Tower 只负责执行已选路线，不负责替玩家做选择

后续任何调参都不应把三条路线重新调成同一种体验。

## 8. 地图匹配设计总结

当前地图结构的优点已经很明确：每个方向都承担独立职责，而不是把整张地图做成平均展开的大平面。

### 8.1 当前最合理的方向分工

- `中上部飞船基地`：恢复、制作、路线确认、结局确认
- `北侧遗迹主线`：终局推进区，负责碎片、石碑、Boss、Signal Tower
- `东侧 swamp`：风险学习区，负责路线管理、状态处理、装备验证
- `西侧回响荒野（Echo Wilds）`：人物调查、潜行追踪、定居主题补强
- `南侧地下沉降带（Subsurface Sink）`：设施控制、风险改写、真相揭示

### 8.2 当前地图匹配为什么是合理的

这套结构之所以合理，是因为它把“叙事阶段”和“空间方向”绑在了一起：

- 玩家先在飞船内部学会恢复、制作、提交与回撤
- 再在森林和东线学会补给、解毒、补氧和中途回退
- 最后才把这些知识回收进北线终局

因此地图并不是“哪里都能平均推进”，而是明确形成：

- `基地 = 准备中心`
- `东线 = 资格考试`
- `北线 = 最终执行`

这正是当前地图最需要保持的匹配关系。

### 8.3 后续最值得继续优化的地图体验点

后续优化应继续围绕下面三件事，而不是重开地图结构讨论：

1. `东线回撤点更清楚`
   让 `Outer Swamp Rim -> Flooded Detour -> Deep Gate -> Deep Basin` 的承诺等级更容易被读懂。
2. `北线提交点更清楚`
   让玩家更容易理解 `Ruins Approach` 是准备段，`Monolith Ring` 是转折段，`Signal Tower Plateau` 是执行段。
3. `西 / 南补完后的职责更稳定`
   让玩家一眼读出“这里是完整的调查线 / 设施线”，而不是“这里少做了一大块地图”。

## 9. 扩展内容处理原则

当前项目的目标是先完成西线 / 南线补完，因此扩展内容应按“当前正式开发目标”来处理，而不是继续把它们当未来保留位。

### 9.1 地图与剧情扩展的当前处理方式

西侧 `回响荒野（Echo Wilds）` 与南侧 `地下沉降带（Subsurface Sink）` 当前应固定视为：

- 正式补完目标
- 主线之外的高价值可玩区
- 会反哺三条成功路线理解与执行的现有内容

它们现在可以继续承担的作用只有：

- 帮玩家确认世界不只由东线 / 北线构成
- 让人物线、设施线与终局线形成闭环
- 给日志、通讯器、地图与结局提供更厚的内容支撑

它们当前不应继续承担：

- 超出西线 / 南线目标之外的额外新主线入口
- 与当前任务链无关的新大型区域
- 无法反哺现有结局的孤立内容包

### 9.2 如果要继续补表现，应该怎么补

如果后续继续补表现，建议优先做下面这些内容：

- 更清楚的西线 / 南线入口说明
- 更一致的地图命名和区域提示
- 能服务任务链的远景 / 残骸 / 地貌装饰
- 能反哺主流程的 lore 补充

不建议再做：

- 超出西线 / 南线方案的新可进入区域
- 需要完全独立资源曲线的新地图块
- 与现有三路线脱节的支线总纲
- 在当前补完前就继续增加更多额外结局分支

### 9.3 当前唯一保留的未来接口位

如果未来真要保留一点额外能力，当前也只建议保留：

- `注册 / 登录 / 账号绑定`

而且这件事必须继续满足：

- 不影响本地离线游玩
- 不阻塞游戏启动
- 不重写当前本地存档主路径
- 独立成单独模块，不侵入当前主循环

原因：

- 没有护栏就先改数值，很容易把“问题”改成“漂移”
- 先锁住终局预算，比先调普通资源更能改善玩家感知

## 7. 推荐的开发任务

### 任务 A：资源刷新规则显式化

至少应完成：

- 把关键资源刷新阈值写进活动文档
- 为 `awayTimer + area` 刷新逻辑补 smoke
- 明确哪些资源故意稀缺，哪些资源故意可循环
- 明确“飞船内资源一次性、飞船外资源可刷新”的边界
- 为 `Stage 1` 关键资源保底（至少 `Ore`）增加防硬锁 smoke
- 把玩家侧刷新提示统一为状态语义，不显示 `95 / 135 / 240` 与刷新次数等底层实现参数

### 任务 B：终局资源预算收口

至少应完成：

- 明确和平路线的 `Relic Fragment` 与 `Energy Core` 总预算
- 把对应信息同步到任务文本、通讯器提示或路线说明
- 避免玩家在 Stage 6 / Stage 7 才发现实际资源需求比预期更高

### 任务 C：战斗 TTK 目标带固定

至少应完成：

- 定义前期 / 中期 / 深区 / Boss 的目标击杀轮次
- 明确激光枪是“显著奖励”还是“过陡跳变”
- 明确石碑与背击叠加后的 Boss 下限击杀轮次
- 同步把“普通怪物是区域唯一威胁、战斗不是主推进核心”的定位写进平衡说明，避免后续又回到大量刷怪的旧思路

### 任务 D：收益可见性验证

至少应完成：

- 验证 Protection Suit 是否足够“穿上就明显更稳”
- 验证 Glow Moss / Calm Mushroom / Shell Fruit / Field Camp 是否足够“带了就感觉不同”
- 验证和平路线是否真的比英雄路线更稳，而不是只改文案

## 8. 验收标准

当以下条件同时满足时，可认为平衡性进入“可持续调优”状态：

1. 关键资源预算已被写清楚
2. 资源刷新逻辑已有测试保护
3. 典型怪物和 Boss 的 TTK 目标带已固定
4. 装备、营地、消耗品的收益能被玩家清楚感知
5. 和平路线、英雄路线、定居路线的准备成本都能被文案与玩法同时解释
6. 资源刷新信息对玩家只呈现“状态级提示”，不呈现底层计时参数

## 9. 当前一句话结论

当前版本的平衡问题，不在于“完全失衡”，而在于：

- `关键曲线已经成立，但还缺透明的护栏和更清楚的经济说明`

## 10. 非当前范围预留

当前平衡计划之外，只允许保留极小的未来能力预留位。

当前唯一明确保留的是：

- `注册 / 登录 / 账号绑定`

但它不属于当前平衡任务，也不应影响本地单机闭环。

如果未来真的进入实现阶段，应先遵守 [`../engineering/FUTURE_RESERVE.md`](/Users/jason/Documents/SpaceCraftLivng/docs/engineering/FUTURE_RESERVE.md) 中定义的边界，再决定是否排期。
