# SpaceCraft Living 重构开发摘要

## 1. 重构目标

本轮重构严格以《SpaceCraft Living》平衡性优化正式版为主设计依据，目标不是继续扩展旧的“飞船舱室逃生”流程，而是将项目重建为一个 `C + raylib` 的轻量化异星生存探索游戏。

本次开发必须优先保留的底层行为：

- 保留原有 `raylib` 主循环与 `Camera2D` 跟随模式
- 保留原有格子移动节奏
- 保留原有基于 Tile 的碰撞判定方式
- 保留原有“输入缓冲 + 移动冷却”的移动手感
- 保留原有轻量化、无额外依赖、可在 macOS 本地直接编译运行的原则

本次需要重做的内容层：

- 地图主题与区域划分
- 主线推进结构
- 生存指标系统
- 资源与制作系统
- 怪物与战斗内容
- 洛希指引与剧情文案
- 资源命名与资源清单文档

## 2. 文档提炼后的核心游戏闭环

游戏主循环应围绕以下闭环展开：

1. 洛希通过便携通讯器提供当前主线目标和生存提示
2. 玩家以格子移动方式探索区域、采集资源、规避或战斗怪物
3. 玩家在探索中承受 `体力 / 压力 / 氧气` 三项生存压力
4. 玩家通过制作基础道具或在基地工作台制作高级道具，解决新区域问题
5. 玩家通过修复飞船部件与完成阶段目标推进剧情阶段
6. 玩家在终局通过 `Boss 通关 / 非战斗信号增幅器通关 / 异星定居` 三条路径触发结局

## 3. 阶段推进摘要

剧情推进从原来的舱室线性流程，调整为 7 个主线阶段，且与昼夜次数解绑：

- 阶段 1：初始苏醒，学习移动、采集、交互，修复氧气基础模块
- 阶段 2：完成坠毁森林前期探索，完整修复氧气系统
- 阶段 3：进入孢子沼泽外围，修复通讯模块基础部分
- 阶段 4：制作防护装备与激光枪，获取坠毁线索
- 阶段 5：击败高威胁怪物或取得替代路径素材，修复能源模块
- 阶段 6：收集遗迹素材、强化装备、解锁信号增幅器配方
- 阶段 7：进入遗迹区域，在终局路径中作出选择并触发结局

## 4. 世界与区域摘要

重构后的地图由四个核心区域组成：

- 飞船基地：安全区、工作台、任务提交、休息、系统修复入口
- 坠毁森林：前期资源区，强调潜行、基础采集和低威胁敌人
- 孢子沼泽：中期压力区，分外围与深处，强调陷阱、毒雾、功能资源
- 遗迹区域：终局区，包含石碑、信号塔、守卫和最终 Boss

## 5. 生存系统摘要

玩家核心生存指标如下：

- 体力：移动、采集、战斗、陷阱都会消耗
- 压力：夜晚、遇敌、陷阱、毒雾、中毒会累计
- 氧气：会随昼夜循环与系统损坏状态持续流失，并与主线修复深度绑定

文档中需要重点实现的惩罚逻辑：

- 压力 30+：效率下降
- 压力 60+：限制高级制作能力
- 压力 80+：视觉干扰、敌人更容易发现玩家
- 压力 100：持续掉体力
- 氧气低位时：降低体力上限并持续加压

## 6. 资源与制作摘要

资源体系分为四层：

- 核心基础资源
- 基础辅助类资源
- 功能强化类资源
- 特殊素材类资源

制作体系分为两层：

- 基础道具：可随地制作
- 高级道具与飞船关键修复：必须在飞船基地工作台完成

## 7. 怪物与通关摘要

战斗与敌人设计采用轻量化实现，重点保留“明确应对策略”而不是复杂 AI：

- 低威胁怪物：用于引导玩家学习战斗和躲避
- 中威胁怪物：结合地形、毒雾、障碍和远程攻击形成中期压力
- 高威胁怪物：遗迹守卫和最终 Boss，用于终局抉择

终局需要支持三种结果：

- 英雄救援结局：击败 Boss 后激活信号塔
- 和平救援结局：制作信号增幅器，绕过 Boss 激活信号塔
- 异星定居结局：修复全部生存系统但不发送信号

## 8. 当前代码重构原则

为了控制开发风险，本轮重构遵循以下落地规则：

- 不破坏现有格子移动、相机跟随、Tile 碰撞的底层逻辑
- 内容系统改造优先于资源文件补齐
- 所有图片与音频先统一命名，继续使用程序化 fallback 绘制与静音兼容
- 新增系统尽量通过静态数组和简单数值逻辑实现，避免引入复杂算法
- 存档结构、UI 文案、资源目录说明需要同步更新，避免代码和文档脱节
