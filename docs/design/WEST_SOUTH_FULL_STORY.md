## 2. 主叙事主轴

本次扩展统一围绕一个核心问题展开：

- 这颗星球上的异常，究竟是自然灾变，还是一套仍在运行的古老系统。

西线负责“人”的问题：

- 失踪船员为何分流
- 为什么有人想留下
- 留下到底是绝望还是选择

南线负责“系统”的问题：

- 毒雾、漏氧、净化设施与石碑网络如何关联
- 玩家是否能接管部分设施，改变世界风险结构

跨区联动负责“立场”的问题：

- 当你知道了船员结局和设施真相，仍然会怎么选终局路线

## 3. 西线完整剧情（W1-W5）

### W1 西向残响

- 触发条件：通讯器修复后，洛希捕捉到一段来自西侧的失真短报文。
- 关键场景：
  - 玩家首次进入 `West Frontier`，发现被改写过的应急路径标识。
  - 在一处半埋信标旁找到第一段船员语音残片："向西，避开塔的视野"。
- 回基地总结：
  - 洛希确认残片来自本船编队成员。
  - 基地日志新增《West Signal Fragment 01》。
- 直接后果：
  - 西线不再是“边界方向”，而是正式调查线。
  - 开放 `W2` 的双节点勘测任务。
- 结局影响：
  - 为定居线和和平线提供第一条“留下并非盲目”的证据。

### W2 断裂勘测线

- 触发条件：完成 `W1`。
- 关键场景：
  - 玩家在 `Survey Break` 依次恢复两处旧勘测锚点。
  - 地图出现撤离箭头反向覆盖，说明船员并非集体逃离，而是主动分流。
  - 第二锚点日志指向“林冠区临时观察营地”。
- 回基地总结：
  - 洛希生成第一版“分流假设”：侦察组与后勤组走了不同路线。
  - 通讯器新增可选汇报分支，允许玩家表达“继续搜寻”或“优先主线”。
- 直接后果：
  - 解锁 `Canopy Hollow` 入口提示。
  - 西线日志从事件描述升级到人物关系线索。
- 结局影响：
  - 英雄线可引用“分流导致救援窗口缩短”的风险依据。

### W3 林冠静默

- 触发条件：完成 `W2`。
- 关键场景：
  - 玩家进入低视距区 `Canopy Hollow`，通过风向标与反射片定位营地。
  - 发现一个被维护过的观察点，证明有人在坠毁后长期存活。
  - 找到“交接记录”：部分船员决定继续西进，部分人回撤尝试接管设施。
- 回基地总结：
  - 洛希将船员状态标记从“失踪”更新为“分流在途”。
  - 基地可读档案新增人物名单与时间线。
- 直接后果：
  - 西线首批收束成立，形成可回访节点。
  - 触发 `W4`：追踪“回声盆地”的汇合信号。
- 结局影响：
  - 定居线获得情感锚点：留下是曾被他人认真评估过的选项。

### W4 回声定位

- 触发条件：完成 `W3`。
- 关键场景：
  - 玩家在 `Echo Basin` 使用三点回声定位重建船员最后通信拓扑。
  - 显示一条关键结论：西进组并未全灭，其中一人将关键数据送往南侧设施入口。
  - 洛希接入后解锁“路线可靠性分析”面板。
- 回基地总结：
  - 基地出现“分流结论简报 V2”。
  - 新增一段洛希对求援风险的重新估计。
- 直接后果：
  - 明确连接西线与南线，推动 `X1` 的跨区对照任务。
  - 开放 `Last Camp` 的最终坐标。
- 结局影响：
  - 和平线可获得更稳定的准备建议。
  - 英雄线会收到“硬闯将放弃部分真相回收”的明确提示。

### W5 最后营地

- 触发条件：完成 `W4`。
- 关键场景：
  - 玩家抵达 `Last Camp`，找到最后留守者的日志盒与手写撤离议定书。
  - 记录明确写下三种立场：立即求援、先稳定环境、尝试长期生存。
  - 玩家需要选择上传哪份摘要给洛希（可全传，但优先结论会影响文案重心）。
- 回基地总结：
  - 洛希生成“船员最终立场对照表”。
  - 基地新增可回看的船员遗留档案合集。
- 直接后果：
  - 西线叙事完整闭环。
  - 触发 `X3` 终局前立场确认。
- 结局影响：
  - 定居线文本显著增强，解释“留下”不再只是玩家临时冲动。
  - 救援线文本会增加“带走记录/传承记忆”的代价感。

## 4. 南线完整剧情（S1-S5）

### S1 沉降裂口

- 触发条件：能源模块恢复后，基地扫描到南侧结构回响。
- 关键场景：
  - 玩家在 `South Collapse` 发现仍有微弱供电的设施外圈。
  - 第一份设施日志提到“净化环离线导致毒雾倒灌”。
  - 出口处出现可交互的应急风阀手轮。
- 回基地总结：
  - 洛希确认南侧属于可控工程结构，不是天然洞穴。
  - 通讯器新增“设施接管”子目标。
- 直接后果：
  - 解锁 `S2` 的通风节点校准任务。
- 结局影响：
  - 为和平线提供“非战斗型推进”依据。

### S2 通风廊校准

- 触发条件：完成 `S1`。
- 关键场景：
  - 玩家在 `Vent Galleries` 依次重启三处通风节点。
  - 地图中部分区域的毒雾显示强度下降，玩家能直观看到风险变化。
  - 日志显示设施曾被船员临时接管但中途放弃。
- 回基地总结：
  - 洛希上报“局部环境参数下降”。
  - 基地提示新增：南线控制会反哺北线准备窗口。
- 直接后果：
  - 开放 `S3` 维修井主回路。
  - 形成第一条南线收益回流。
- 结局影响：
  - 和平线准备阶段获得更清晰的可行性说明。

### S3 维修井回路

- 触发条件：完成 `S2`。
- 关键场景：
  - 玩家在 `Service Shafts` 接通主回路，打通一条飞船到深区的结构捷径。
  - 在井壁终端读取到“南侧设施与石碑网络曾发生同步异常”。
  - 完成后主地图往返时出现明显节奏优化。
- 回基地总结：
  - 洛希标注“设施回流已成立”。
  - 基地新增“南侧维护记录”归档页。
- 直接后果：
  - 南线首批闭环成立。
  - 开启 `S4` 的净化环重启权限。
- 结局影响：
  - 英雄线可获得更稳定的补给路线。

### S4 净化环重启

- 触发条件：完成 `S3`。
- 关键场景：
  - 玩家在 `Purifier Ring` 依序恢复净化、密封、供氧三类控制单元。
  - 每恢复一类单元，都会在至少一个主线区域体现真实风险下降。
  - 末端控制台揭示：石碑不是污染源，而是“压制失稳”的次级控制端。
- 回基地总结：
  - 洛希输出“全局风险改写报告”。
  - 通讯器新增终局前建议：不同结局所需准备条件更明确。
- 直接后果：
  - 解锁 `Root Vault` 深层入口。
  - 推动 `X2`：洛希对终局策略的重写。
- 结局影响：
  - 和平线文本从“理论可行”升级为“工程可行”。

### S5 根系密库

- 触发条件：完成 `S4`。
- 关键场景：
  - 玩家在 `Root Vault` 下载核心结构记录，确认塔、石碑、净化设施为同源体系。
  - 记录指出坠毁后异常加剧，主要因维护链断裂而非单一敌对意志。
  - 玩家将选择上传“完整真相”或“行动摘要优先”。
- 回基地总结：
  - 洛希生成系统级结论：终局不再是“打或不打”，而是“带着哪套认知行动”。
  - 基地档案新增《Root Vault Core Dossier》。
- 直接后果：
  - 南线叙事闭环完成。
  - 解锁 `X3` 的最终立场确认。
- 结局影响：
  - 三条成功结局都会出现南线真相引用段落。

## 5. 跨区联动剧情（X1-X3）

### X1 痕迹对照

- 触发条件：完成 `W3` 与 `S2`。
- 关键场景：
  - 玩家把西线船员记录与南线设施维护记录进行时间戳比对。
  - 发现“西进组给南线组留过校准窗口”，两线首次形成闭环证据。
- 回基地总结：
  - 洛希修正“船员行为模型”：从失序逃亡改为分工协作。
- 直接后果：
  - 开启终局提示中的“协作遗产”关键词。
- 结局影响：
  - 定居线与和平线的语义支撑同步增强。

### X2 洛希同步重写

- 触发条件：完成 `W4` 与 `S4`。
- 关键场景：
  - 洛希对求援、镇压、稳定三种策略进行再估算并公开权重变化。
  - 玩家可在终局前看到可视化对照：风险、代价、信息保留度。
- 回基地总结：
  - 通讯器与 objective 的终局提示文本统一改写。
- 直接后果：
  - 终局抉择不再只看资源够不够，也看认知立场。
- 结局影响：
  - 三条路线都会体现“你知道了什么”与“你选择了什么”的差异。

### X3 留下还是离开

- 触发条件：完成 `W5` 与 `S5`。
- 关键场景：
  - 终局前，玩家在基地完成一次“行动宣言”确认。
  - 该确认不会锁死路线，但会决定结局文案的叙事重心。
- 回基地总结：
  - 洛希给出最终任务摘要，明确每条路线的意义与代价。
- 直接后果：
  - 西线与南线成果正式并入终局叙事层。
- 结局影响：
  - 英雄：强调代价与承担。
  - 和平：强调修复与协作。
  - 定居：强调传承与长期生存。

## 6. 结局反哺矩阵

| 结局 | 西线贡献 | 南线贡献 | 跨区贡献 |
| --- | --- | --- | --- |
| 英雄救援 | 船员分流证据提高行动代价感 | 设施回流提供执行稳定性 | 行动宣言强调“明知代价仍选择承担” |
| 和平救援 | 船员遗留记录补强“为何值得谈判/稳定” | 净化环与密封控制提供工程可行性 | 洛希重写策略让和平线不再像隐藏选项 |
| 定居 | 最后营地档案提供定居伦理与情感依据 | 根系密库给出长期维护知识 | 对照任务证明“留下”有历史连续性 |
| 失败结局 | 可引用“线索已发现但未完成整合” | 可引用“设施可控但未完成接管” | 强化失败并非随机，而是准备不足 |

## 7. 落地优先级建议

为避免一次性改动过大，建议按下面顺序落地剧情文本与演出：

1. 先补 `W4`、`S4`，建立第二轮可玩性与全局收益变化。
2. 再补 `W5`、`S5`，完成人物线与系统线双收束。
3. 最后补 `X1-X3`，统一终局前文案、提示与结局引用。
