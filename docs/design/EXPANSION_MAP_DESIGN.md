## 2. 设计前提

当前扩展地图设计必须遵守以下固定前提：

- 当前版本已经存在可独立成立的 `Stage 1 - Stage 7` 闭环
- `北主线 / 东风险 / 西南预留` 的总方向不能被推翻
- 西侧与南侧扩展不能抢走当前北线终局区的主线职责
- 扩展区应提供“世界补充、准备收益、叙事分支”，而不是把玩家重新拉进另一套主线
- 扩展区必须继续服务于 `出门 -> 风险判断 -> 获取线索/资源 -> 回撤 -> 制作/恢复 -> 再出门` 的核心循环

一句话概括：

- `扩展地图不是拿来把世界变大，而是拿来把世界变深`

## 3. 扩展后的世界结构

### 3.1 宏观方向

扩展完成后的世界结构建议固定为：

- `中央偏上`：飞船基地与森林教学区
- `正上方`：遗迹、石碑、Boss、Signal Tower 主线终局区
- `右侧`：swamp 风险与准备区
- `左侧`：`回响荒野（Echo Wilds）` 调查 / 潜行 / 失踪船员区
- `下方`：`地下沉降带（Subsurface Sink）` 设施 / 调度 / 真相揭示区

方向职责保持清晰：

- 北侧回答“主线怎么收束”
- 东侧回答“准备为什么重要”
- 西侧回答“还有谁活过、留下了什么、为什么有人选择不回去”
- 南侧回答“这个星球和飞船事故到底发生了什么”

### 3.2 扩展后的路线关系

扩展地图不建议做成四块彼此孤立的大方块，而应形成以下关系：

- `飞船 -> 西侧`：最自然的中期调查支线入口
- `飞船 -> 南侧`：最自然的后期设施探索入口
- `东侧深沼 -> 南侧中层`：形成一次关键的侧向穿插
- `西侧高点 -> 北侧前段`：只建立“视野和情报关联”，不直接变成主线捷径

原则：

- 西侧更多提供 `信息、线索、观察收益`
- 南侧更多提供 `环境控制、路线质量、设施收益`
- 二者都应反哺主地图，而不是只在自己的区域内自转

### 3.3 当前代码版布局的冻结与重排约束

基于当前代码版地图布局，本轮文档先固定下面这组前提，后续代码改动以此为准：

- `北线冻结`
  `Ruins Approach -> Monolith Ring -> Signal Tower Plateau` 的整体结构、入口关系与终局职责先不动。
- `东线冻结`
  `Outer Swamp Rim -> Flooded Detour -> Deep Gate -> Deep Basin` 的节奏、深度分层与主线推进职责先不动。
- `只重排西线与南线`
  当前允许调整的是 `Echo Wilds` 与 `Subsurface Sink` 的空间组织、命名分段边界、landmark 分布和区域尺度读感。
- `不改区域名与任务顺序`
  `West Frontier -> Survey Break -> Canopy Hollow -> Echo Basin -> Last Camp`
  与
  `South Collapse -> Vent Galleries -> Service Shafts -> Purifier Ring -> Root Vault`
  这两条顺序链保持不变。
- `重排目标不是加新区域`
  重点是把现有命名区域做得更大、更开、更有内部层次，而不是新增第六段、第七段支线区。

### 3.4 当前代码版识别出的空间问题

从当前代码版布局看，西线与南线已经具备命名分区与任务挂接，但空间读感仍有两类明显问题：

- `西线偏窄`
  当前更像沿左侧边缘连续排开的调查条带，`Echo Basin` 与 `Last Camp` 也偏像同一片深处口袋的相邻切片。
- `南线偏贴底`
  当前更像贴着南边界依次拼接的几块设施平台，`Purifier Ring` 与 `Root Vault` 之间的层级落差不够明显。
- `地标偏集中`
  日志、怪物压力点、资源点和视觉焦点仍然偏向局部堆叠，导致“区域名字很多，但每段内部空间不够展开”。
- `留白位置不对`
  现在更像“路线外大面积空旷，路线内相对紧凑”，而目标应是“每个命名区域内部有足够尺度，区域之间靠结构差异分开”。

### 3.5 施工级总图说明

下面这组说明不是概念描述，而是后续真正改地图时应直接照着执行的总图约束。

#### 3.5.1 冻结区与可动区

- `北线`
  继续维持 `Ruins Approach -> Monolith Ring -> Signal Tower Plateau` 的三段北上结构，不挪入口，不挪主线执行关系。
- `东线`
  继续维持 `Outer Swamp Rim -> Flooded Detour -> Deep Gate -> Deep Basin` 的四段东进结构，不改深浅分层，不改主线推进职责。
- `西线`
  允许扩大区域占地、重画分段边界、重摆地标与怪物压力点，但不改 `W1 -> W5` 的顺序和命名。
- `南线`
  允许扩大区域占地、重画设施层次、重摆日志和控制节点，但不改 `S1 -> S5` 的顺序和命名。

#### 3.5.2 世界平面上的占位关系

后续重排时，整张地图应被读成下面这套关系：

- `飞船 + 森林`
  保持在中上部，仍然是玩家回撤、补给、判断的中心。
- `北线`
  保持在飞船正北，不与西南扩容发生重叠。
- `东线`
  保持在飞船右侧与右下方向，不被南线向东挤压。
- `西线`
  应占据飞船左侧到左下方向的一整片宽调查带，而不是只贴左边界形成一条竖线。
- `南线`
  应占据飞船下方到右下前的宽设施带，但要在进入东线深区前收束，不与 `Deep Gate / Deep Basin` 混成同一片。

#### 3.5.3 西线与南线之间的关系

- 两条线应 `彼此可在叙事上呼应，但空间上仍然分家`。
- 中间应保留一段 `森林/断层缓冲带`，让玩家知道两条线互有关联，但不能让它们变成随便横穿的一张大广场。
- 从高层设计上看：
  西线负责 `横向搜寻`
  南线负责 `层级下潜`
- 玩家从西线获取的信息，应能解释南线日志；
  玩家从南线得到的设施真相，应能反向解释西线调查结果。
  但地图上不应该通过一条过于直接的捷径把两条线硬缝成一条主路。

#### 3.5.4 区域尺度的相对要求

后续制作时，不要求文档先写死精确坐标，但必须满足下面这组相对尺度：

- `West Frontier` 必须明显大于现在的入口条带，至少能同时容纳入口识别、第一批痕迹和回撤观察。
- `Survey Break` 不应比 `West Frontier` 更小，它要像真正的第一段调查面，而不是连接通道。
- `Canopy Hollow` 应是西线中段最大的潜行空间之一。
- `Echo Basin` 必须是西线单块最有“空间感”的区域。
- `Last Camp` 可以不是最大，但必须是最完整、最独立、最安静的终点空间。
- `South Collapse` 必须足够大到像设施前厅，而不是南边界开出来的一个门洞。
- `Vent Galleries` 应是第一段能明显读出设施身份的展开区。
- `Service Shafts` 不是一条线，而是一块能分配上层、下层、回路和捷径的骨架区。
- `Purifier Ring` 必须是南线最清楚的核心设施大区。
- `Root Vault` 不一定比净化环更宽，但必须比它更深、更收束、更像终点核心。

#### 3.5.5 施工顺序要求

真正实现时，应按下面顺序做，而不是边画边凑：

1. 先确定 `西线/南线的大地块边界`
2. 再确定 `每段命名区域的切分线`
3. 再确定 `每段的主 landmark`
4. 再摆 `日志、互动点、怪物压力点`
5. 最后才补 `树、石头、围挡、留白装饰`

如果顺序反过来，就很容易再次做成“先堆装饰，再拿命名去解释”的假分区。

## 4. 解锁节奏建议

| 扩展区 | 首次明确提示时机 | 正式开放时机建议 | 主要服务阶段 |
| --- | --- | --- | --- |
| `回响荒野（Echo Wilds）` | `Stage 3 - Stage 4` | `Stage 4` 之后 | `Stage 4 - Stage 6` |
| `地下沉降带（Subsurface Sink）` | `Stage 5` | `Stage 5` 之后 | `Stage 5 - Stage 7` |

节奏原则：

- 西侧比南侧更早开放，因为它承担人物与世界补充，不应晚到玩家已经准备收尾才出现
- 南侧比西侧更晚开放，因为它承担设施调度与真相揭示，更适合作为后期“高价值准备线”
- 第一版扩展不建议追加强制性的 `Stage 8`
- 扩展区首次上线时，应先作为 `可选高价值支线`，而不是改写原主线流程

## 5. 西侧扩展区：回响荒野（Echo Wilds）

### 5.1 区域定位

`回响荒野（Echo Wilds）` 的核心定位应固定为：

- 失踪船员搜寻区
- 中后期调查与潜行区
- 低毒压 / 中氧耗 / 高信息密度区
- 通过线索、视野、声音与踪迹推进的支线区域

它要与东侧 swamp 明确区分：

- swamp 让玩家学会“准备不足会被环境压垮”
- 回响荒野让玩家学会“准备得再足，也不该鲁莽进入未知视线和追踪网”

当前固定约束：

- 常规怪不会继续增加数量
- 回响荒野只承担 `3` 个常规怪压力点：`West Frontier`、`Canopy Hollow`、`Echo Basin`
- `Survey Break` 与 `Last Camp` 应以调查、路线判断和日志直取为主，不再额外塞入常规怪

### 5.2 核心玩法关键词

- `追踪`
- `潜行`
- `视线管理`
- `声源判断`
- `调查拼图`

这里不建议复用 swamp 的“毒雾更重、怪更强”逻辑，而应强调：

- 环境本身没有深沼那么致命
- 但路线辨识更难，误判更容易导致绕远、暴露或错过关键线索
- 玩家不是单纯去采更多资源，而是去确认“谁来过、谁留下了什么、是否还有人活着”

### 5.3 子区域结构建议

#### `West Frontier`

定位：

- 当前版本已存在的保留边界
- 扩展后的正式入口与过渡区

职责：

- 作为飞船西行后的第一段教学缓冲
- 把“这里只是未来方向”升级成“这里已经是实际搜寻边界”
- 放置第一批搜寻线索、地标和封锁说明

应包含：

- 边界标识
- 倒塌调查桩
- 第一处失踪船员痕迹
- 返回飞船的清晰回撤感

#### `Survey Break`

定位：

- 第一段真正进入回响荒野的调查走廊

职责：

- 用坠毁勘测设备、断裂天线、拖行痕迹、临时营地残骸建立“搜寻现场”感
- 让玩家第一次需要在 `追线索` 和 `控制暴露` 之间做取舍

玩法重点：

- 分叉线索
- 视野盲角
- 早期潜行收益

#### `Canopy Hollow`

定位：

- 西侧扩展的中段核心区

职责：

- 建立高植被、低视距、绕行价值高的探索结构
- 强化绕路、掩护、观察怪物巡逻的玩法存在感，不再依赖单独蹲伏按键

玩法重点：

- 低视距穿行
- 声音诱导
- 高度依赖环境遮蔽

#### `Echo Basin`

定位：

- 西侧扩展的情报与空间识别中心

职责：

- 用异常回声、信号折返和高低差形成“观察比冲刺更有价值”的玩法层
- 让玩家在这里拼出失踪船员路径、调查结论和西侧支线的真正方向

玩法重点：

- 高点观察
- 信号反射 / 残留定位
- 地图局部重解释

#### `Last Camp`

定位：

- 西侧扩展第一轮的情感高点与阶段收束点

职责：

- 告诉玩家失踪船员支线的第一轮答案
- 给出“返回、定居、等待救援、主动离开”这些主题的情感锚点
- 为后续新支线或新结局提供人物基础

这里不一定要直接给出完整真相，但必须给出：

- 清晰的人类痕迹
- 明确的选择痕迹
- 能反向影响主地图理解的记录内容
- 相对安静、允许玩家专注阅读和回收日志的空间收束感

### 5.4 西侧路线组织原则

西侧应避免做成“大树林 + 大量岔路”的空耗型地图，而应遵守：

- 每一段都必须有一个可识别 landmark
- 每深入一层，都要让玩家得到新的调查结论，而不是只有新资源
- 至少每两段区域应出现一个可回撤的小安全点或观察点
- 回程应比去程更快，避免潜行区二次重复拖长时间

基于当前代码版布局，西线下一轮重排应额外满足：

- `整体读感从“边缘窄条”改成“宽搜寻带”`
  玩家进入西线后，应该感觉自己在进入一片横向展开的调查区域，而不是沿世界左边缘贴墙走。
- `West Frontier` 要更像入口扇面
  这里不应只是第一块小前哨，而应有足够横向空间容纳边界标识、第一处痕迹和回撤视野。
- `Survey Break` 与 `Canopy Hollow` 要真正拉开
  两段之间应通过折线、错层或视线差异分开，而不是只靠名字切换。
- `Echo Basin` 要成为真正的大盆地区
  这里应能同时容纳高点观察、回声定位、日志回收和回程切口，不再只是深处角落里的一个小格子。
- `Last Camp` 要成为独立终点口袋
  它应明显脱离 `Echo Basin` 的主体空间，形成安静、收束、可阅读的最终营地，而不是紧贴盆地边缘。
- `西线地标要分散摆放`
  日志、怪物压力点、观察点、回程捷径和资源点应分摊到五段空间里，避免多个关键点挤在同一片纵深。

建议的单次外出节奏：

1. 从飞船西侧出发
2. 在 `West Frontier` 校准目标
3. 进入 `Survey Break` 获取明确追踪线
4. 穿过 `Canopy Hollow` 控制暴露
5. 在 `Echo Basin` 完成定位或确认
6. 到 `Last Camp` 触发关键调查节点
7. 通过回程捷径撤回飞船

### 5.5 西线施工蓝图

下面这部分应被视为 `Echo Wilds` 的施工级描述。后续如果开始改代码，地图实现应尽量能一一对应到这些句子。

#### 5.5.1 西线总形状

西线不应再是“左边界往下拉一条长带”，而应做成 `前窄后宽、再收束` 的调查地形。

具体读感应为：

- 从飞船出去后先进入一个 `较宽但安全的入口扇面`
- 随后进入 `被痕迹和断裂勘测线切开的调查面`
- 再进入 `低视距、高遮蔽` 的林冠中段
- 然后突然展开到一个 `能看见高差与回声结构的大盆地区`
- 最后收束到一个 `安静、独立、可停留阅读` 的终点营地

也就是说，西线的形状应是：

- `入口扇面`
- `中段折线调查面`
- `中后段低视距潜行面`
- `深处大盆地`
- `更深处独立营地口袋`

而不是：

- 一条直走廊
- 一串边界平台
- 一个盆地加一个紧贴盆地边上的终点角落

#### 5.5.2 西线主路与支路

西线应同时存在 `主调查路` 和 `辅助观察/回撤路`。

主调查路承担：

- 让玩家按 `West Frontier -> Survey Break -> Canopy Hollow -> Echo Basin -> Last Camp` 逐步推进
- 每一段都先看到一个主 landmark，再读出下一段方向
- 让任务 marker 和日志顺序天然成立

辅助观察/回撤路承担：

- 提供高点、观察点、小安全点
- 让玩家在至少两段之间存在“先观察再推进”的选择
- 在 `Echo Basin` 或 `Last Camp` 之后提供明显比来时更快的回撤路线

必须避免：

- 主路和支路在绝大部分时间里完全平行
- 所有支路都变成资源死胡同
- 回程还要完整重复一次潜行主流程

#### 5.5.3 各分段怎么做

`West Frontier`

- 应做成一个 `横向比纵向更宽` 的入口前沿。
- 玩家从飞船出来后，第一眼要同时看到：
  一处边界标识、一组调查残骸、一个继续向西的明确方向。
- 区域内部应允许玩家稍微左右展开，而不是只能沿单线往下走。
- 第一份西线日志应落在这里，但不放在最边缘角落，而是放在“玩家已经正式跨进西线”的位置。
- 这里可以有怪物压力，但压力应更像“提醒这是调查线”，而不是直接把入口变成战斗卡口。

`Survey Break`

- 应是西线第一块真正有面积的调查地块。
- 这里要能放下：
  断裂勘测设备、断天线、拖行痕迹、两个以上可读的分叉方向。
- 玩家到这里后，应感觉“信息突然变多”，而不是“路还是那条路，只是名字变了”。
- 这里最好存在一处短暂高点或观察坡，让玩家第一次从上往下看调查现场。
- 这一段的关键不是战斗，而是让玩家学会顺着痕迹走。

`Canopy Hollow`

- 应是西线中段最明显的低视距空间。
- 区域内部不能太空，必须有足够多的树、残骸、观察点和遮蔽带，支持绕路与潜行。
- 这里的可走区域不应是一整块平地，而应由多个遮蔽岛、窄口和斜切路径组成。
- 怪物压力点应放在这里，但怪物应服务于“观察巡逻、找时机穿过”，而不是堵死单一路口。
- 日志或观察营地应落在一个相对安全的侧 pocket，让玩家完成穿越后能短暂停下来读信息。

`Echo Basin`

- 这里必须是西线最有地形识别度的一段。
- 进入时，玩家应明显感觉空间突然变大，视野从林冠压迫转成“高低差 + 回声定位”的判断。
- 这里至少要同时具备：
  一个高点、一个盆地主体、一个侧向回声点、一个通往 `Last Camp` 的收束出口。
- 盆地主体不能被大量石头塞满，否则“盆地”会读成杂乱空地。
- 高点不能只是装饰，它必须能让玩家理解下一段方向，或者重新解释西线前面拿到的信息。
- 西线最关键的一份中后段日志应放在这里，而且应落在“完成观察或定位后自然抵达”的位置，而不是顺路随手捡。

`Last Camp`

- 必须和 `Echo Basin` 通过一个明显的收束段相连。
- 玩家进入这里时，要感到自己离开了开放调查面，进入了一个被选择和停留痕迹定义的终点空间。
- 营地内应清楚看见：
  停留痕迹、整理过的物资、选择的证据、终局立场的情感锚点。
- 这里应尽量减少无意义绕路，因为它的核心价值是阅读、理解和情绪收束。
- 回程捷径可以从这里或这里前一段开启，但不应破坏这里的独立性。

#### 5.5.4 西线 landmark 摆放规则

西线的 landmark 不只是“好看”，而是每段区域的识别器。最少应包含下面这几类：

- `入口 landmark`
  负责告诉玩家“这里不是森林尾巴，而是西线起点”
- `调查 landmark`
  负责告诉玩家“这里正在发生可以被追踪和拼接的信息链”
- `潜行 landmark`
  负责告诉玩家“这里的重点是观察和绕行，不是直冲”
- `定位 landmark`
  负责告诉玩家“这里要把信息收束成结论”
- `终点 landmark`
  负责告诉玩家“这里是答案，不是下一段路的过渡”

落位原则：

- 每段至少 `1` 个主 landmark
- 相邻两段的 landmark 类型不能一样
- landmark 应优先落在 `玩家进入该段后 3-8 秒内能看到的位置`
- 不能把所有最大地标都放在深处，导致前中段缺少识别点

#### 5.5.5 西线日志、怪物、资源怎么摆

日志：

- 五份日志必须一段一份，且应落在“完成这一段的核心理解动作之后”。
- 日志不能只当成奖励，应同时承担“这一段为何成立”的解释功能。

怪物：

- 只放在 `West Frontier`、`Canopy Hollow`、`Echo Basin`。
- 入口怪物负责建立风险感，中段怪物负责潜行与观察，盆地区怪物负责定位压力。
- 不要让 `Survey Break` 和 `Last Camp` 被战斗打断它们的剧情功能。

资源：

- 西线资源应服务于“再走一段”而不是“刷一轮回家”。
- 资源可见度应高于东线深沼，因为西线的重点不是生存资格考试。
- 中后段资源应更多出现在观察点、回撤路和 pocket 里，而不是强行塞在主路中心。

#### 5.5.6 西线实现时的否决项

如果出现下面任意一种情况，就说明实现偏了：

- 玩家进入西线后仍然只是在地图左边贴边往下走
- `Echo Basin` 和 `Last Camp` 看起来像同一片空间的两个标签
- `Survey Break` 与 `Canopy Hollow` 只能靠 UI 名字区分
- 回程还要重复穿一次完整的潜行主路
- 五段区域里有两段以上没有明确 landmark

- 玩家第一次踏进每一段时，`3-5` 秒内到底先读到什么。
- 这一段是让玩家 `观察`、`追踪`、`潜行`、`定位` 还是 `收束`。
- 这份日志为什么必须放在这里，而不是别的段。
- 这一段如果做歪，玩家会把它误读成什么。

### 5.6 西侧对主地图的反哺

西侧扩展最重要的不是多一块地，而是为现有地图带来这些收益：

- 给北线终局区提供更强的世界观与人物动机
- 给定居路线提供更扎实的情感理由
- 给和平路线补充“为什么不一定只有离开才是胜利”的证据
- 给通讯器、日志、地图 Overlay 增加可积累的调查信息

建议的收益类型：

- 更清楚的北线风险情报
- 关于失踪船员的日志与地标记录
- 新的临时补给点或观察点说明
- 未来角色线、营地升级或 settlement 扩展的前置条件

## 6. 南侧扩展区：地下沉降带（Subsurface Sink）

### 6.1 区域定位

`地下沉降带（Subsurface Sink）` 的核心定位应固定为：

- 后期设施探索区
- 高价值环境控制区
- 世界真相与系统根源揭示区
- 高压但可被“正确准备和正确调度”主动改写的区域

它与北侧、东侧的差异应该非常明确：

- 北侧强调主线收束
- 东侧强调生存准备
- 南侧强调设施控制和环境重塑

### 6.2 核心玩法关键词

- `设施控制`
- `环境改写`
- `节点调度`
- `上下层循环`
- `高风险短程推进`

南侧不应只是“更难的深沼泽”。

它应该让玩家感受到：

- 这里危险，但危险是可以被改变的
- 正确操作节点后，路线本身会变短、变稳或变清晰
- 成功的关键不只是多背药，而是理解结构

### 6.3 子区域结构建议

#### `South Collapse`

定位：

- 当前版本已存在的保留边界
- 扩展后的正式入口与地形前厅

职责：

- 保留现有坍陷、断裂、封锁语义
- 升级为南侧扩展的“入口广场”
- 让玩家在这里理解南侧不是普通洞穴，而是沉入地下的设施网络

#### `Vent Galleries`

定位：

- 南侧扩展的第一层危险过渡区

职责：

- 建立热流、漏氧、视野分段与短路径绕行的风险认知
- 教会玩家南侧的危险是“结构性”的，而不是只靠怪物堆起来的

玩法重点：

- 节点开关
- 热区 / 冷区切换
- 安全窗口判断

#### `Service Shafts`

定位：

- 南侧扩展的中层交通骨架

职责：

- 让南侧不只是平面展开，而是有明确的上下层组织
- 形成回飞船、回东侧、继续下潜三种路线选择

玩法重点：

- 电力与门禁切换
- 立体短路与回环捷径
- 中途设施恢复点

#### `Purifier Ring`

定位：

- 南侧扩展的核心设施环

职责：

- 承担“玩家主动改变环境”的第一轮高价值反馈
- 让玩家通过控制净化、供氧、密封等设施，真实改变南侧或主地图的部分风险

玩法重点：

- 多节点顺序控制
- 风险与收益的区域级切换
- 回程路线明显优于去程

#### `Root Vault`

定位：

- 南侧扩展第一轮的真相节点与高压收束点

职责：

- 揭示石碑网络、毒雾、供氧异常与信号塔之间的底层联系
- 为未来新增路线、额外结局或更高层设施线留下叙事支点
- 让玩家理解这颗星球“看起来像自然灾难，实际上带有人造结构痕迹”

### 6.4 南侧路线组织原则

南侧应采用“环 + 轴 + 竖向节点”结构，而不是单纯的长走廊。

建议组织方式：

- `入口轴线`：South Collapse -> Vent Galleries
- `中层环线`：Service Shafts -> Purifier Ring
- `深层终点`：Root Vault

必须做到：

- 第一次进入时看起来危险复杂
- 第二次进入时，因为设施已改变而明显更可读
- 玩家能感觉到“这片区域被我驯服了一部分”

基于当前代码版布局，南线下一轮重排应额外满足：

- `整体读感从“贴底平台串联”改成“宽设施带”`
  玩家进入南线后，应该看到一条被塌陷和设施切开的地下带状结构，而不是南边界上的几块短甲板。
- `South Collapse` 要更像入口前厅
  这里应有足够空间建立“塌陷前厅 + 设施入口 + 第一批事故痕迹”的组合读感。
- `Vent Galleries` 不能只是一小段过道
  它需要成为第一段真正可识别的设施区，能容纳通风节点、视野分段和第一轮安全窗口判断。
- `Service Shafts` 要成为中层骨架
  不只是通往后续区域的过渡段，而是能把回撤、横向切换和继续下潜统一起来的主骨架。
- `Purifier Ring` 必须比相邻区更大、更完整
  玩家需要在空间尺度上感到自己真的进入了“核心设施环”，而不是进入又一块相似的平台。
- `Root Vault` 要与净化环拉开
  它应作为更深、更静、更收束的终点核心，不能紧贴 `Purifier Ring` 末端像同一间大房的附角。
- `南线地标要横向摊开`
  事故入口、通风日志、井道同步点、净化环控制简报和根脉核心档案，应分别落在不同深度与不同横向位置上。

### 6.5 南线施工蓝图

下面这部分应被视为 `Subsurface Sink` 的施工级描述。后续真正实现时，南线的地形、控制点和日志摆位应尽量能逐条对应到这里。

#### 6.5.1 南线总形状

南线不应做成“底边连续摆四个平台”，而应做成 `前厅 -> 设施带 -> 中层骨架 -> 核心环 -> 深层核心` 的层级结构。

具体读感应为：

- 玩家先从南侧入口进入一个 `塌陷 + 半埋设施` 的前厅
- 随后进入 `有明显通风和供氧结构` 的第一层设施带
- 再进入 `承担上下层切换和回路组织` 的井道骨架
- 之后进入一个明显更完整、更规则的 `净化环核心设施区`
- 最后进入 `更深、更静、更集中` 的根脉核心

也就是说，南线必须同时具备：

- `横向展开`
  让玩家看到这是一整片设施系统，而不是一条向下的洞
- `纵向递进`
  让玩家知道自己在越来越深入系统核心

缺一不可。

#### 6.5.2 南线主轴、环线与回路

南线应有三种不同功能的路线：

- `入口主轴`
  负责把玩家从 `South Collapse` 带进 `Vent Galleries`
- `中层骨架`
  负责通过 `Service Shafts` 组织上下层与回撤
- `核心环线`
  负责让 `Purifier Ring` 读成可以被接管和改写的设施环，而不是一次性穿过的单走廊

回路设计要求：

- 玩家第一次来时，路线应看起来复杂、封闭、带风险
- 玩家完成节点控制后，至少一条回程路线应明显缩短
- 路线优化应来自 `设施被恢复`，而不是凭空打开一个方便门

必须避免：

- `Service Shafts` 只是一个细长通道
- `Purifier Ring` 没有成环或半环感
- `Root Vault` 直接贴在 `Purifier Ring` 后面，像同一大区的尾巴

#### 6.5.3 各分段怎么做

`South Collapse`

- 应做成南线入口前厅，而不是一段南边缘门廊。
- 第一眼应让玩家同时看到：
  塌陷结构、半埋设施、继续向下的系统入口。
- 这里要负责建立“南线是设施线”的第一印象，所以应优先出现人工结构痕迹而不是纯自然洞窟。
- 第一份南线日志应放在这里，但位置应像“事故入口记录”，不是随便掉在边角的拾取物。
- 这里可以有怪物压力，但怪物功能应是提醒玩家南线危险，不应遮盖设施阅读。

`Vent Galleries`

- 必须是第一块真正让玩家看到“环境可被控制”的区域。
- 区域内部要能摆下：
  通风结构、漏氧区、相对安全点、绕行口和第一批控制节点。
- 玩家在这里应第一次明确感知：
  同样的路，开关前后读感不同。
- 这段不能做成单通道，因为玩家需要在这里学“看结构做决定”。
- 日志应放在玩家理解“通风系统正在改变整段体验”之后自然能抵达的位置。

`Service Shafts`

- 应是南线真正的中层骨架区。
- 这里至少要支持三种读感：
  继续下潜、回到前段、切到更稳或更快的辅助路。
- 井道、门禁、维修通道和半恢复节点应成为这里的主体，而不是背景贴图。
- 这里的怪物压力应更像“系统深处开始反咬你”，而不是普通地下战斗。
- 一旦这一段完成，玩家必须能明显感觉后续南线和部分主地图往返变得更顺。

`Purifier Ring`

- 必须是南线最能体现“我在接管系统”的区域。
- 进入这里时，视觉上应从塌陷、破损转为更完整、更规则的设施构造。
- 这里至少要同时具备：
  净化节点、密封节点、供氧节点、中心控制解释点。
- 三类节点最好不要挤在同一个小房间里，而应让玩家有“按顺序接管一圈设施”的感受。
- 区域中心应有一个能被读成“设施主心脏”的视觉焦点。
- 文档里的“真实改写环境”必须在空间上可理解，也就是玩家能看懂自己到底改了哪一圈设施。

`Root Vault`

- 必须是南线最收束的一段。
- 这里不应再强调复杂路线，而应强调“进入核心、获取最终真相”的压缩感。
- 空间上应从 `Purifier Ring` 的较开阔设施区，转成一个更深、更静、更聚焦的核心腔室。
- 最关键的南线终局日志应放在这里，并且应出现在一个明显像“核心档案位”的位置。
- 如果这里看起来像普通设施房的延长段，就说明实现失败。

#### 6.5.4 南线 landmark 与控制点摆放规则

南线至少应有下面这些 landmark / 控制点类型：

- `事故入口 landmark`
  告诉玩家这里是坍陷后的设施入口
- `通风 landmark`
  告诉玩家这里的风险来自系统状态，而不是纯地形
- `井道 landmark`
  告诉玩家这里是结构骨架和路线切换核心
- `净化 landmark`
  告诉玩家这里是系统改写的真正执行点
- `核心档案 landmark`
  告诉玩家这里是答案与真相的收束点

落位原则：

- 每段至少 `1` 个主 landmark
- `Purifier Ring` 至少应有 `1` 个中心 landmark + `2-3` 个功能节点
- landmark 优先放在“玩家进入该段后很快就能识别到此段身份”的位置
- 控制点之间要有明确前后关系，不能全堆在一个画面里

#### 6.5.5 南线日志、怪物、资源怎么摆

日志：

- 五份南线日志也必须一段一份。
- 每份日志都要和该段设施身份强绑定：
  入口事故、通风交接、井道同步、净化控制、根脉核心。

怪物：

- 只放在 `South Collapse`、`Service Shafts`、`Root Vault`。
- 入口怪物负责建立南线危险，井道怪物负责施加系统深处压力，根脉核心怪物负责守住最终真相。
- `Vent Galleries` 与 `Purifier Ring` 不应被常规怪物干扰它们的节点控制职责。

资源：

- 南线资源应更多服务于“支撑设施推进”，而不是鼓励玩家在这里刷循环采集。
- 资源点应围绕控制节点、回撤路和半恢复设施摆放。
- `Purifier Ring` 与 `Root Vault` 的资源可见度可以比西线更低，因为它们的重点是设施与真相，不是调查残留。

#### 6.5.6 南线实现时的否决项

如果出现下面任意一种情况，就说明实现偏了：

- 玩家对南线的第一印象仍然是“南边多了几块平台”
- `Vent Galleries` 只能靠名字分辨，空间上看不出它是通风设施区
- `Service Shafts` 只承担过路功能，无法读出骨架身份
- `Purifier Ring` 没有明显中心，不像一套核心设施
- `Root Vault` 看起来像 `Purifier Ring` 的附属小房间
- 玩家完成设施控制后，路线品质没有明显改善

#### 6.5.7 南线五段施工表

下表应被直接视为 `Subsurface Sink` 的分段施工说明。后续如果进入实际实现，至少应做到“做出来的地图和这张表能逐项对上”。

| 分段 | 玩家进入时第一眼应看到什么 | 主空间形状 | 主 landmark | 玩家在本段的核心动作 | 日志建议落位 | 怪物 / 风险角色 | 回程或捷径设计 | 实现备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `South Collapse` | 塌陷结构、半埋设施、继续向下的系统入口 | `设施前厅`，比门廊更宽，能建立入口身份 | 坍塌入口框架 / 事故断面 | 确认“南线是设施线”，理解这里不是普通地下洞窟 | 放在像事故入口记录台的位置，不放在边角 | 有入口风险感，但不应盖过设施身份 | 这里主要负责建立回撤认知，真正捷径在后段形成 | 如果玩家第一眼读成“南边又多一块平台”，说明前厅没成立 |
| `Vent Galleries` | 通风结构、漏氧区、安全窗口、第一批控制节点 | `第一层设施带`，可横向展开，不是直走过道 | 通风主机 / 风道观测点 | 学会看节点、看安全窗口、理解环境可以被控制 | 放在完成一次有效通风切换后自然能到的位置 | 重点是结构性风险，不安排常规怪物打断阅读 | 可在这里首次看到“未来回程会更顺”的结构伏笔 | 如果不能一眼看出这是通风设施区，说明身份失败 |
| `Service Shafts` | 井道骨架、门禁、维修通道、继续下潜与回撤分叉 | `中层骨架区`，不是一条线，而是一个可组织回路的区域 | 主井道节点 / 维修回路交汇点 | 组织路线，决定继续下潜、回撤或切换到更优路径 | 放在玩家真正理解“这些井道连着主地图和深区”之后 | 承担南线中层压力，怪物像系统深处开始反咬玩家 | 这里完成后，必须实际打开更顺的回飞船或回中段路线 | 如果这里只剩“通过一下”，说明骨架身份没有成立 |
| `Purifier Ring` | 更完整、更规则的核心设施、中心焦点、多个控制节点 | `核心设施环` 或 `半环 + 中心`，必须能读成一整套系统 | 净化环中心控制核 | 按顺序接管净化、密封、供氧，理解自己在改写整片环境 | 放在完成核心控制链后自然抵达的解释点 | 不安排常规怪物，重点是节点控制与区域级收益切换 | 完成后应显著出现比来时更短或更稳的回程 | 如果玩家看不懂自己到底接管了哪一圈设施，说明核心环失败 |
| `Root Vault` | 更深、更静、更聚焦的核心腔室，档案位是视觉中心 | `终点核心腔室`，更深而更收束，不是净化环附角 | 根脉核心档案位 | 获取最终真相，完成系统级理解和终局准备 | 放在明显像“核心档案位”的位置，不能像散落拾取物 | 可承担最终真相守卫压力，但重点仍是收束而非清怪 | 可从本段或前段解锁最终回撤捷径，但不破坏核心感 | 如果这里像普通设施房延长段，或者和净化环连成一片大平层，说明终点失败 |

南线施工时，开发者至少应能用这张表回答下面这些问题：

- 玩家为什么会把某一段读成 `前厅`、`设施带`、`骨架`、`核心环` 或 `核心腔室`。
- 哪一段负责第一次教会玩家“环境是可以被改变的”。
- 哪一段负责真正给出“路线质量变好了”的收益。
- 为什么 `Purifier Ring` 和 `Root Vault` 不能做成一大块连续平台。

### 6.6 南侧对主地图的反哺

南侧的收益应直接改善现有主地图体验，而不是只给一个剧情结论。

建议反哺方向：

- 降低某些区域的氧气压力或漏氧惩罚
- 开启新的中途供氧节点、净化节点或设施恢复点
- 给北线终局提供更稳定的和平路线或补给型路线
- 给东线深区提供更合理的往返窗口

设计原则：

- 南侧收益必须改变“路线质量”，不只是给玩家更多数值
- 玩家完成关键设施后，应该能在地图与通讯器上立刻感知变化

## 7. 两块扩展区的差异化要求

| 维度 | 回响荒野（Echo Wilds） | 地下沉降带（Subsurface Sink） |
| --- | --- | --- |
| 主主题 | 调查、踪迹、失踪船员 | 设施、调度、世界真相 |
| 主要风险 | 迷向、暴露、被追踪 | 过热、静电、漏氧、结构失稳 |
| 地图读感 | 横向搜寻、视野遮挡、高点观察 | 纵向下潜、节点环线、设施控制 |
| 主要收益 | 情报、人物线、调查结论 | 环境改写、路线优化、设施控制权 |
| 服务当前主线方式 | 强化动机与世界理解 | 强化准备质量与终局稳定性 |

验收标准：

- 玩家进西侧时，感觉是在“搜寻与判断”
- 玩家进南侧时，感觉是在“接管与调度”
- 两块区域都不能做成“换皮版高压地图”

## 8. 扩展区与现有系统的接线原则

### 8.1 对生存系统的要求

扩展区必须继续围绕 `血量 + 氧气 + 状态栏` 设计，不应重新发明独立生存面板。

建议：

- 西侧优先承接 `迷向 / 被锁定 / 潮湿` 这类轻状态方向
- 南侧优先承接 `过热 / 静电干扰 / 净化场保护 / 强化密封` 这类设施型状态方向

但首批落地时仍应控制复杂度：

- 可以先用当前已有状态和环境判定模拟核心体验
- 不必在扩展首批同时上线过多全新状态

### 8.2 对地图与 UI 的要求

扩展上线后，以下界面必须同步：

- 地图 Overlay
- minimap
- 通讯器区域说明
- 日志与调查记录
- objective marker 与路线提示

要求：

- 新区域命名必须简短、稳定、可读
- 子区域名必须能自然进入地图和通讯器文案
- 不能出现“地图叫 A，通讯器叫 B，日志叫 C”的割裂命名

### 8.3 对恢复点与捷径的要求

扩展区一旦变长，必须同步补安全点，不允许单纯加距离。

建议最低配置：

- 西侧至少 `1` 个观察营地 + `1` 条回程捷径
- 南侧至少 `1` 个设施恢复点 + `1` 个回飞船捷径 + `1` 个连回东侧的结构出口

### 8.4 施工时必须一口气想清楚的表

如果后续要真正开做地图，至少应先把下面这几张表补齐，然后再动代码：

1. `分段边界表`
   写清楚每个命名区域与相邻区域的边界依据是什么，是地势、设施断层、视线变化还是功能切换。
2. `主 landmark 表`
   写清楚每段最先让玩家识别这段身份的是什么。
3. `日志落位表`
   写清楚每份日志放在哪、为什么放那、玩家做完什么动作后会自然拿到。
4. `怪物压力表`
   写清楚哪些段有怪、怪是为了什么，不允许只写“这里放一个怪”。
5. `回撤与捷径表`
   写清楚玩家从哪里回、为什么第二次回来更快。

如果这五张表写不出来，就说明地图方案还没有详细到可施工。

## 9. 首轮落地边界建议

如果后续真的开做扩展区，第一轮不要试图把两块地图一次性做满。

更合理的第一轮范围是：

- 西侧先做到 `West Frontier + Survey Break + Canopy Hollow`
- 南侧先做到 `South Collapse + Vent Galleries + Service Shafts`
- 先确认路线骨架、地标、回撤与收益是否成立
- `Echo Basin / Last Camp / Purifier Ring / Root Vault` 作为第二轮深化内容

这样做的好处：

- 可以先验证西侧是否真的和东侧风险体验拉开差异
- 可以先验证南侧设施玩法是否真的比“多带补给”更有价值
- 不会在第一轮就把地图体量扩得失控

## 10. 扩展地图验收清单

当以下条件同时满足时，可认为扩展地图设计进入可开发状态：

1. 扩展后的世界方向仍然一眼可读
2. 西侧和南侧各自回答的问题足够不同
3. 扩展区对现有主地图存在明确反哺
4. 每块扩展区都已经拆出入口、中段、收束点与回程结构
5. 不依赖新增大量系统也能成立第一轮体验
6. 地图、文本、状态方向、设施职责之间没有明显冲突
7. 只看文档，开发者就能说清每个命名区域的主路、支路、landmark、日志位和回程结构
8. 只看文档，开发者就能分辨哪些留白是故意的，哪些空地是必须补成可读空间的
