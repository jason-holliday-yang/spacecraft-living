## 2. 当前总体判断

项目已经具备稳定可玩的主循环，而且新一版 `血量 + 氧气 + 状态栏` 体验已经进入实际运行代码。

当前可以明确认定已经成立的事情：

- `Stage 1 - Stage 7` 主线骨架可跑通
- 左下角 HUD 已显示 `状态栏 -> 血量条 -> 氧气条`
- 状态图标悬浮 Tooltip 已有运行时实现
- 中毒、漏氧、低氧、窒息、危急状态、过滤呼吸、营地恢复等状态已经进入统一状态系统
- 游戏内天数按真实游玩时间累计，约 `5` 分钟算 `1` 天；睡觉会快进 `60` 秒，并只在跨天时提示新的一天开始
- 基地、营地、消耗品、防护服已经开始围绕新资源模型提供恢复和状态处理
- 主线推进已经进一步偏向 `求生 + 调查真相 + 回船确认路线`，而不是靠连续战斗强推

但这不代表系统已经彻底收尾。

当前更准确的判断应该是：

- `玩家可见体验` 已大体切到新设计
- `底层运行时与存档` 仍处于新旧混合兼容状态
- `地图总布局` 已经完成核心方向收口，并应视为最终定版布局
- `飞船主通道 + 上下船舱`、`北线三段终局路线`、`东线四段风险路线` 已形成统一命名与导航反馈
- `采集 / 攻击 / 高级制作` 的主要门槛已转到 `health + oxygen + status`，不再由旧 `stress / stamina` 直接主导玩家可见玩法
- `14` 份已接线日志的详细描述已经接入洛希终端详情流，阅读器不再只是空占位
- 当前更准确地说，主要设计目标都已经落地；剩余工作更偏向 `兼容字段清理`、`数值平衡`、`终局体验补强` 与 `可选美术资源补图`

一句话概括：

- `生存系统已从“纯目标设计”进入“混合落地 + 收尾清理”阶段`
- `当前总优先级已经固定为跨区整合、终局体验补强、平衡调整、兼容清理与发布级收尾`

### 2.1 中文术语统一

当前代码与文档中的中文专有名词，后续统一以设计文档中的定名为准：

- `洛希（Loxi）` 是唯一正式中文译名，不再使用旧误写

- 资源 / 消耗品统一写作：`植物果实`、`特殊菌株`、`发光苔`、`异星藤蔓`、`壳果`、`能源核心`、`能量晶体`、`宁神蘑菇`、`防护纤维`、`遗迹碎片`、`守卫鳞片`、`异星黏液`、`复苏口粮`

### 2.2 当前完整性与可玩性判断

如果只问“它现在是不是一个完整可玩的游戏”，当前开发口径应明确为：

- `是`

如果再进一步问“它是不是已经进入可直接视为正式完整版发布的状态”，当前开发口径应明确为：

- `还不是`

更准确的表述应该是：

- `当前版本已经不是原型，也不是只有系统碎片的半成品`
- `当前版本已经具备从开场、游玩、死亡结算、存档读档到多结局收束的完整闭环`
- `当前版本更接近“完整可玩的收尾阶段版本”，而不是“彻底完成的正式版”`

基于当前代码、测试与构建验证，可以确认已经成立的事情：

- 主程序可以稳定构建
- 会话层 smoke 已覆盖 `开局 -> 开场 -> 游玩 -> 读档 -> 死亡弹窗 -> 重新开始 / 读档`
- 终局 smoke 已覆盖 `英雄 / 和平 / 定居` 三条成功路线
- 生存系统 smoke 已覆盖 `血量 / 氧气 / 状态栏` 的关键运行时体验

但当前仍然阻止它被对外表述成“已彻底完成”的主要原因包括：

- 结局后的产品级闭环还不够完整，当前更接近“看完结局后退出程序”
- 北线终局演出与东线节奏还需要继续补强，当前是“能通”但不是“完全打磨完”
- 西侧 / 南侧完整任务链虽然已经接入运行时，但跨区 `X1-X3` 的终局反哺与提示层仍需继续补强
- 底层仍保留一部分兼容字段与旧语义，说明系统收尾尚未结束

因此，当前最合理的对外和对内开发口径应统一为：

- `完整可玩`
- `尚未完全收尾`
- `后续优先级应继续围绕发布级可玩性和维护性收口`

## 4. 当前仍然存在的关键差距

### 4.0 直接影响完整性与可玩性的缺口

## 6. 当前最推荐的开发顺序

基于当前代码真实状态，后续开发顺序建议固定为：

1. 先修正基地归档判定中的旧房间命名残留，确保回船总结与任务归档稳定可信
2. 再补一个更明确的“真相整理 / 回看 / 拼装”步骤，让终局选择不只是在条件满足后自动开放
3. 再继续深化 `X1-X3` 的表现层：终局页、洛希终端、路线确认弹层与结局后复盘
4. 再补 `结算得分系统`，把主线、日志、生存表现、固定遭遇和结局完成统一收进结算页
5. 再清理日志奖励相关的兼容字段与旧文案，把日志价值彻底收束为叙事、归档与评分
6. 再补关键资源预算、刷新规则和战斗曲线的平衡护栏
7. 再继续清理日志奖励、存档 schema 文档和旧语义，避免 `stamina / pressure` 从兼容层回流到玩法层
8. 再补强北侧终局区的事件反馈、路线奖惩和演出读感，并继续把英雄路线 Boss 战区收口成世界内北线西北遗迹的高质量终局战
9. 再微调东侧 swamp 的外围 / 深区节奏与准备收益
10. 最后补测试覆盖、文档同步与发布级闭环收口

不建议把下面这些继续当成当前 P0：

- 再单独开一轮“HUD 是否改版”
- 再单独开一轮“状态栏是否存在”
- 先大量新增怪物和新系统
