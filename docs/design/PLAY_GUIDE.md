# SpaceCraft Living 游玩文档（精简版）

## 1. 游戏目标
- 在资源紧张和环境风险下生存，逐步修复飞船系统。
- 在求生过程中回收日志、拼合真相，并通过任务推进剧情。
- 完成阶段任务后回到飞船与洛希（Loxi）做出最终路线选择，再执行对应的救援或定居结局。
- 战斗不是主线核心；很多推进来自调查、准备和日志解锁。

## 2. 核心按键
- `WASD` / 方向键：移动
- `F`：交互（采集、修理、阅读、工作台制作）
- `Space`：攻击
- `B`：背包
- `N`：洛希面板（第一次与洛希终端同步后开放，显示当前任务 + 日志）
- `M`：地图
- `H`：帮助
- `O`：设置
- `X`：快速使用复苏口粮
- `ESC`：暂停

## 3. 七段主线流程
1. Wake Up（苏醒）：采集木材和金属残片，修好氧气控制台。
2. First Steps（迈出第一步）：采集发光苔与矿石，制作荧光棒，完成氧气修复。
3. Into the Wild（走向荒野）：打开东侧气闸，采集异星藤蔓 / 壳果 / 特殊菌株，修复通讯中继。
4. Rising Risk（风险升级）：制作激光枪与防护服，调查坠毁线索。
5. Power Breakthrough（动力突破）：前往沼泽深处获取能源核心，回基地修复电力舱。
6. Final Preparation（最终准备）：在北部遗迹收集 3 个遗迹碎片，回洛希终端同步。
7. Final Choice（最终抉择）：完成西线 / 南线调查与终局日志回收，回到飞船与洛希选择强行救援、和平救援或异星定居路线；强行救援会把目标固定为世界内北线西北遗迹的守卫战，和平救援则携带信号放大器前往信号塔，定居路线在飞船内完成最终确认。

## 4. 地图与解锁
- 东线：中前期主推进线（通讯与能源相关），以环境风险为主，不靠常规怪堆压力。
- 北线：后期遗迹与最终路线，常规情况下只有石碑区守护者。
- 西线：通讯修复后开放，承担人物调查线与一半常规怪压力。
- 南线：电力舱修复后开放，承担设施真相线与另一半常规怪压力。

## 5. 生存优先级
1. 先看氧气，再看血量。
2. 低氧、漏氧、高中毒时优先撤退。
3. 深区探索前先做装备检查（防护服、补给、回撤路线）。
4. 基地/营地是恢复与重整节点，长线路前先补给。

## 5.1 时间规则
- 游戏内天数按真实游玩时间累计，约 `5` 分钟算 `1` 天。
- 睡觉会快进 `60` 秒，只在跨天时提示下一天开始。
- 界面现在更强调环境阶段，而不是固定天数数字。

## 6. 制作与推进建议
1. 关键制作优先级：照明 -> 武器/防护 -> 长线探索支援。
2. 深区任务尽量带解毒与氧气补给；如果已经能进工作台制作，优先准备 `复苏口粮（Recovery Ration）`。
3. 日志分布固定为：飞船 `3` 份、东线主线异常记录 `1` 份、西线 `5` 份、南线 `5` 份。卡进度时先看 `N` 面板目标与当前待完成任务。
4. 西线 / 南线不是每份日志都要靠战斗拿到：一部分在怪物压力区，一部分是直接调查拾取。
5. 任务卡住时再确认地图上的当前路线是否已解锁。

## 7. 结局说明
- 强行救援（Heroic Rescue）：先在飞船与洛希确认强行救援路线；随后从正常世界路线推进北线，进入西北遗迹完成守卫战。击败守卫后返回信号塔完成发射。
- 和平救援（Peaceful Rescue）：先在飞船与洛希确认和平救援路线，再携带信号放大器稳定信号塔。
- 异星定居（Settlement）：先在飞船与洛希明确确认，关闭两条救援路线后进入定居结局。
- 死亡结束（Failure / Run Over）：生命值归零后本轮立刻结束，只能重新开始或读档。
- 当前账号只要经历过一次死亡结束或任意成功结局，主菜单右上角都会显示该账号的最高得分。

## 9. 快速排错
- 感觉太难推进：先回基地补给，再做短线往返，不要一次压太深。
- 氧气总是不够：用 `植物果实 + 壳果 + 特殊菌株 + 发光苔 + 宁神蘑菇` 在工作台制作 `复苏口粮`，按 `X` 或在背包里使用后可同时恢复生命、解毒、补氧并获得短暂氧气储备。
- 资源不够：优先完成当前阶段关键资源，非关键采集可延后。
- 路线不开放：优先补前置修复（通讯或电力）。
- 强行救援卡住：先回飞船与洛希完成路线确认，再沿北线推进到西北遗迹完成守卫战；没有打赢守卫前，信号塔不会进入最终发射。
