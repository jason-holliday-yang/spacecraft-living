# SpaceCraft Living 日志档案详细描述与资源 Brief（2026-04-17）

## 1. 文档定位

本文档用于统一扩写后 `26` 份日志 / 档案的两个层面：

- 文案层：每份日志的详细剧情描述、叙事职责、情绪基调
- 资源层：每份日志对应的画面 brief，方便后续生成剧情图、整理素材与统一资源命名

当前采用的扩写目标口径：

- 飞船日志 `5`
- 东线日志 `3`
- 西线日志 `7`
- 南线日志 `7`
- 北线 / 跨区 / 终局日志 `4`

说明：

- 本文档中的 `brief` 主要服务于剧情图制作，不替代后续更细的出图 prompt
- 当前已接线的 `14` 份日志图片，运行时正式路径以 [`../../resources/images/README.md`](/Users/jason/Documents/SpaceCraftLivng/resources/images/README.md) 为准，即 `resources/images/story/logs/log_##_<scene_slug>.png`
- 本文档里的 `草案文件名` 仅用于出图生产、版本迭代和内部协作，不应直接覆盖当前运行时已经接线的 `log_01-log_14` 资源名
- `Loxi Synthesis` 当前仍应理解为写作层 / 表现层归档，不是现有运行时 UI 的第三种正式档案分类

## 2. Brief 固定字段

每份日志的资源 brief 统一使用以下字段：

- `草案文件名`
- `当前运行时路径（若已接线）`
- `中文标题`
- `剧情位置`
- `画面主体`
- `构图建议`
- `情绪关键词`
- `必须出现元素`
- `禁止出现元素`

补充说明：

- `当前运行时路径（若已接线）` 是可选字段；只有当该剧情图已经正式进入运行时代码时才填写。
- 仅用于写作扩写或资源预研的条目，保留 `草案文件名` 即可。

默认画风基线：

- 若条目已经进入运行时，后续修图应优先复用现有 `log_##` 编号，不再另起一套正式资源命名
- 若条目尚未接线，再使用 `草案文件名` 作为出图阶段工作名，等确认接线后并入正式 `log_##` 路径
- `retro pixel art cinematic game cutscene`
- `sci-fi survival`
- `detailed pixel art`
- `dramatic lighting`
- `atmospheric fog`
- `teal and blue palette with subtle orange accents`
- 同一个宇航员角色设计保持一致
