# SpaceCraft Living 状态系统映射表（2026-04-07）

> 当前状态说明：本文档仍属于活动设计文档，当前优先级是支撑西线 / 南线补完与终局整合；其中“预留状态 / 预留设施”段落仅作后续可选备忘。

## 1. 文档目的

本文档用于补齐新版 `血量 + 氧气 + 状态栏` 体系的落地映射规则。

它回答的问题是：

- 哪些区域会触发哪些状态
- 哪些怪物会施加哪些状态
- 哪些道具和装备可以解除、缓解或强化状态
- 基地、营地、设施在新系统里分别承担什么职责

阅读顺序建议：

2. 再看本文档

## 2. HUD 与状态栏布局

左下角目标布局固定为：

- 第一行：状态栏
- 第二行：血量条
- 第三行：氧气条

状态栏显示规则：

- 最多显示 `6` 个状态图标
- 负面状态优先靠左
- 正面状态靠后
- 同类状态通过等级升级表现，不重复占多个格子
- 超出显示上限时，末格显示 `+N`

状态栏 tooltip 统一包含：

- 状态名
- 当前效果
- 触发来源
- 解除方式
- 当前等级 / 持续信息

## 3. 状态列表

### 3.1 首批负面状态

#### 中毒 Poisoned

定位：

- 第一个核心异常状态

效果：

- 持续损失血量
- 提高氧气消耗

等级：

- 轻度
- 中度
- 重度

主要来源：

- 深层沼泽毒雾
- 毒性怪物攻击
- 污染残骸

主要解除方式：

- 解毒类消耗品
- 营地缓解
- 基地医疗设施完全清除

#### 氧气泄漏 Oxygen Leak

定位：

- 由重击、尖刺、遗迹危险或设备事故触发的异常状态

效果：

- 额外消耗氧气
- 使低氧和窒息更早到来

等级建议：

- 轻微泄漏
- 严重泄漏

主要解除方式：

- 密封剂
- 营地临时修补
- 基地完整修复

#### 低氧 Low Oxygen

定位：

- 氧气低于阈值时自动触发的警告状态

效果：

- 强调玩家进入撤退窗口
- 以提示为主，惩罚轻于窒息

触发阈值建议：

- 氧气低于 `25%`

#### 窒息 Suffocating

定位：

- 氧气极低时触发的致命状态

效果：

- 持续损失血量
- 拥有最高显示优先级

触发阈值建议：

- 氧气低于 `10%`
- 氧气归零后持续存在

#### 重伤 Critical Condition

定位：

- 血量过低时触发的危险状态

效果：

- 强烈提示玩家应立即撤退
- 初版以反馈为主，不建议叠加过多硬性惩罚

触发阈值建议：

- 血量低于 `30%`

### 3.2 首批正面状态

#### 过滤防护 Filtered

定位：

- 防护服、滤芯、特殊药剂带来的正面状态

效果：

- 降低危险区域耗氧
- 降低中毒累积速度
- 降低异常状态升级速度

#### 氧气储备 Oxygen Reserve

定位：

- 便携氧气罐、应急供氧装置带来的正面状态

效果：

- 提供额外的短期续航层
- 延后低氧和窒息到来时间

#### 营地休整 Camp Recovery

定位：

- 在 Field Camp 完成休息后获得的短时状态

效果：

- 小幅回血
- 小幅补氧或降低耗氧
- 小幅延缓异常状态恶化

## 4. 区域到状态的映射

### 4.1 飞船基地

区域职责：

- 完整恢复点
- 完整清异常点
- 关键制作点

区域风险：

- 无持续耗氧压力
- 不主动施加负面状态

主要状态互动：

- 清除 `中毒`
- 清除 `氧气泄漏`
- 解除 `低氧`
- 结束 `窒息`
- 如未来确有必要补充轻量正面状态，也应作为独立预留处理，不进入当前版本排期

节奏要求：

- 飞船内部交互要按照 `主通道 -> 舱室` 的结构自然串联
- 玩家在飞船内应主要感受到“准备”和“恢复”，而不是风险压迫

### 4.2 坠毁森林

区域职责：

- 前期低耗氧教学区
- 潜行与基础探索区

区域风险：

- 缓慢耗氧
- 夜间视野劣势
- 轻度战斗威胁

主要状态互动：

- 通常不主动施加 `中毒`
- 夜间更容易触发 `低氧`
- 如未来需要补充轻度环境状态，可单独评估 `寒冷` 或 `潮湿`，但这不属于当前版本目标

### 4.3 孢子沼泽外围

区域职责：

- 中期路线管理区
- 补给准备价值验证区

区域风险：

- 中速耗氧
- 更长路线
- 更多追击怪和更少安全点

主要状态互动：

- 更容易触发 `低氧`
- 某些怪可能施加 `氧气泄漏`
- 少量污染点可作为 `中毒` 的早期预演

平衡要求：

- 应让玩家开始重视 Rope、Field Camp、Shell Fruit，而不是立刻强行要求全套高阶装备
- 压力来源应以路线长度和中等耗氧为主，不应过早进入“重中毒 + 重漏氧”的复合惩罚

### 4.4 孢子沼泽深处

区域职责：

- 高风险状态区
- 过滤、防护、解毒系统主舞台

区域风险：

- 快速耗氧
- 毒雾覆盖
- 持续污染

主要状态互动：

- 高概率施加 `中毒`
- 高速逼近 `低氧`
- 在重度中毒下更容易进入 `窒息`
- `过滤防护` 在此区域价值最高

平衡要求：

- 深沼泽应是“学会处理状态”的区域，而不是“学会读档”的区域
- Calm Mushroom、Glow Moss、Protection Suit、Field Camp 在这里都必须有明确感知收益
- 玩家必须存在撤退窗口，不能因为一次接敌或一次踩毒就直接崩盘

### 4.5 遗迹

区域职责：

- 终局高压区
- 路线与准备判断区

区域风险：

- 高耗氧
- 高威胁战斗
- 特定机关危险

主要状态互动：

- 可触发 `氧气泄漏`
- 低氧与窒息更容易出现
- 如未来确有必要补充遗迹专属环境状态，应单独评估，不进入当前版本排期

平衡要求：

- 遗迹应回收前面学到的准备逻辑，而不是重新发明一套完全不同的生存惩罚
- 英雄路线强调战斗与减压路线，和平路线强调装置准备与稳定推进
- 石碑应降低终局风险，但不能替代准备本身

## 4.6 非当前范围状态预留方向

以下内容仅保留为“第二轮以后可选扩展”的状态备忘。当前阶段优先级是完成西线 / 南线任务链补完，不以新增大量状态种类为近期目标。

### 西侧回声林地

更适合承接的状态：

- `迷向`
- `被锁定`
- `寒冷` 或 `潮湿` 这类轻环境状态

设计原则：

- 不与 swamp 的中毒 / 过滤玩法高度重复
- 以探索、调查、潜行为主

### 南侧地核沉降层

更适合承接的状态：

- `过热`
- `静电干扰`
- `净化场保护`
- `强化密封`

设计原则：

- 更强调设施交互、区域控制和高阶路线规划
- 让玩家主动改变环境风险，而不只是被动抗压

## 5. 怪物到状态的映射建议

### 5.1 前期怪物

定位：

- 教会玩家“受伤”和“撤退”的基本节奏

建议效果：

- 主要造成血量伤害
- 少量怪可以造成轻微 `氧气泄漏`
- 不建议前期高频施加 `中毒`

### 5.2 中期怪物

定位：

- 强化区域风险而不是只堆高伤害

建议效果：

- 一部分怪造成直接血量伤害
- 一部分怪制造 `氧气泄漏`
- 沼泽怪可引入 `轻度中毒`

### 5.3 深区怪物

定位：

- 与环境状态形成组合压迫

建议效果：

- 可造成 `中毒`
- 可造成 `严重氧气泄漏`
- 可逼迫玩家在继续战斗和撤退之间选择

### 5.4 Boss 与终局威胁

定位：

- 终局资源压力的综合检验

建议效果：

- 直接高额血量伤害
- 特定技能施加 `氧气泄漏`
- 特定阶段可配合遗迹环境把玩家推入 `低氧` 或 `窒息` 风险

设计原则：

- Boss 压力应来自 `血量 + 氧气 + 状态`
- 不应只依赖高伤害

## 6. 道具与消耗品映射

### 6.1 食物类

职责重定位：

- 主要负责回血
- 可附带轻微恢复增益

建议映射：

- `Fruit`：小幅回血
- `Shell Fruit`：中幅回血并提供短时移动增益或恢复效率增益
- 组合食用：更强恢复，但不建议替代专业医疗资源

### 6.2 药用与蘑菇类

职责重定位：

- 不再叫“减压力资源”
- 改为状态处理资源

建议映射：

- `Calm Mushroom`：缓解 `中毒` 或稳定异常恶化
- `Special Fungus`：临时获得 `过滤防护` 或提高解毒效率
- 组合使用：更强的状态清理或短时稳定效果

### 6.3 补氧类

建议新增或映射出的道具职责：

- 便携氧气罐：获得 `氧气储备`
- 应急供氧包：直接补氧
- 密封剂：清除或降低 `氧气泄漏`

平衡要求：

- 补氧类道具必须明显区别于纯回血资源
- 其价值应体现在“多走一段 / 多撑一次撤退 / 多一次终局尝试”，而不是只回一点数值

## 7. 装备映射

### 7.1 Glow Stick

新职责：

- 降低夜间探索的信息劣势
- 间接减少无效绕路导致的耗氧

### 7.2 Rope

新职责：

- 把路线缩短
- 降低长距离探索带来的耗氧风险

### 7.3 Laser Gun

新职责：

- 降低近身战造成的血量损失与异常状态风险
- 帮助玩家在高风险区更快清理威胁

### 7.4 Protection Suit

新职责：

- 获得或强化 `过滤防护`
- 降低危险区耗氧
- 降低 `中毒` 累积速度
- 降低 `氧气泄漏` 恶化速度

### 7.5 Signal Amplifier

新职责：

- 和平路线的关键装置
- 不直接参与生存条，但决定终局分支资格

### 7.6 Field Camp

新职责：

- 野外部分恢复点
- 获得 `营地休整`
- 缓解部分异常状态
- 不替代基地完整恢复

可玩性要求：

- 营地不只是回血点，还必须成为路线规划的一部分
- 当前营地职责应完全围绕现有地图成立，不再以西侧 / 南侧新增可玩区作为设计前提

## 8. 设施映射

### 8.1 基地设施

统一职责：

- 完整回血
- 完整补氧
- 完整清异常
- 制作与阶段提交

### 8.2 野外营地

统一职责：

- 部分回血
- 部分补氧
- 有限清异常
- 给玩家继续推进一个短窗口

### 8.3 非当前范围设施备忘

以下内容仅保留为低优先级备忘，不进入当前版本排期：

- 医疗站：强化异常清除
- 过滤站：强化危险区探索前准备
- 供氧终端：在遗迹中提供一次性补氧

## 9. 状态优先级建议

建议显示优先级从高到低如下：

1. `窒息`
2. `重度中毒`
3. `严重氧气泄漏`
4. `重伤`
5. `低氧`
6. `中度中毒`
7. `轻度氧气泄漏`
8. `过滤防护`
9. `氧气储备`
10. `营地休整`

原则：

- 越致命的状态越靠左
- 越能直接导致死亡的状态优先级越高
- 正面状态不应盖过负面危险状态

## 10. 非当前范围状态备忘

以下状态只作为备忘，不代表当前版本继续扩展新地图、新剧情主线或大型玩法系统：

负面备忘：

- `感染`
- `寒冷`
- `震荡`
- `污染附着`

正面备忘：

- `饱食`
- `止痛`
- `战术专注`
- `基地支援`

当前建议：

- 首批不要一次做太多状态
- 先用 `中毒 + 氧气泄漏 + 低氧 + 窒息 + 过滤防护 + 营地休整` 验证系统

## 11. 本文档对后续开发的要求

任何新增状态都应先回答：

- 它是负面状态、正面状态还是自动警告状态？
- 它影响血量、氧气，还是两者都影响？
- 它的触发来源是什么？
- 它的解除方式是什么？
- 它是否真的值得占一个状态栏位置？

如果回答不清楚，就不应直接加入系统。

另外还应确认：

- 它服务的是剧情流畅度、区域辨识度，还是单纯增加一个新图标？
- 它是否会和已有状态产生重复职责？
- 它是否会把当前区域的平衡从“可预判”推向“过度堆叠”？
