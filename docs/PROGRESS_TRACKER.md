## 🔧 使用说明

### 如何更新进度

1. **每日站会后更新**:
   - 更新任务状态 (未开始 → 进行中 → 已完成)
   - 更新燃尽图
   - 填写每日更新日志

2. **里程碑达成后更新**:
   - 标记里程碑为已完成 [✓]
   - 更新总体进度百分比
   - 更新系统完成度表格

3. **遇到问题时更新**:
   - 在风险追踪中添加新风险
   - 记录应对措施
   - 更新风险状态

### 符号说明

- ✅ 已完成
- ⏳ 进行中
- 🔮 待开始
- 🟡 监控中 (风险)
- 🟢 正常 (风险)
- 🔴 高风险
- [✓] 已达成里程碑
- [ ] 未完成里程碑
