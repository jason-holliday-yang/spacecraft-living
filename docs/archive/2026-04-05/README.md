# 2026-04-05 历史归档摘要

这批归档主要对应“C 与 C++ 混合重构”的阶段性迁移记录。

## 当时文档关注的问题

那一轮文档的重点是：

- 统一 `Makefile` 与 `CMakeLists.txt`
- 把平台、持久化、资源路径等更适合封装的模块迁移到 C++
- 保持 public header 的 C ABI
- 逐步把 `game_manager`、存档、资源加载、UI 切片从大单体模块里拆出

## 为什么不再单独保留旧迁移报告

原始迁移报告已经与当前工程文档高度重合，而活动文档现在更准确：

- 当前工程结构看 [`../../engineering/ARCHITECTURE.md`](../../engineering/ARCHITECTURE.md)
- 当前迁移策略看 [`../../engineering/CPP_MIGRATION_PLAN.md`](../../engineering/CPP_MIGRATION_PLAN.md)

旧报告更像“某一时刻的迁移中间态”，继续保留全文只会制造重复入口，因此已删除。

## 仍然保留的历史结论

这一轮重构真正留下来的长期结论只有三条：

- 核心玩法与热路径更新继续优先留在 `C`
- 会话、持久化、内容表、平台抽象更适合逐步迁移到 `C++`
- 迁移必须和 smoke 测试绑定，避免把语言切换和规则改动混在一起

这三条原则都已经进入当前活动文档，因此本归档只保留摘要。
