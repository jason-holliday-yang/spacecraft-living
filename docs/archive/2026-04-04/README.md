- 开发计划与任务清单

### 2. 早期状态判断

该阶段的很多结论已经过期，例如：

- 以百分比衡量项目完成度

这些内容现在均已被活动文档覆盖，不再适合作为当前依据。

### 3. 仍然有参考价值的历史信息

保留下来的历史价值主要只有三类：

- 早期为何优先做 Rope / Puzzle / Log
