# 文档归档说明

`docs/archive/` 只保留“仍值得查阅的历史背景”，不再保留大量彼此重复的周报、完成度看板和阶段日志。

## 归档整理原则

- 当前有效结论统一留在活动文档中
- 历史记录只保留少量浓缩摘要
- 多份内容高度重复的旧报告、旧计划、旧清单已删除
