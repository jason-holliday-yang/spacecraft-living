# SpaceCraft Living 后续开发与完善计划（2026-04-09）

> 当前状态说明：本文件仅保留为历史参考，不再作为当前活动开发文档。当前真正执行应以平衡调优、稳定性修复、维护性整理与发布收尾为主。

## 1. 当前阶段目标

在不破坏当前可玩版本的前提下，把项目推进到下面这个状态：

- 地图方向感清楚
- 飞船内部结构清楚
- 主线推进与区域风险分工清楚
- 扩展内容有明确预留边界
- 工程层可以继续扩展而不重新长回超大文件

当前最重要的前提变化是：

- `血量 + 氧气 + 状态栏` 的玩家可见体验已经基本落地
- 后续总优先级已经从“证明新生存系统存在”切到“围绕新生存系统重构地图与扩展边界”
- 地图重构的核心 phase 现已完成第一轮落地，后续主线应继续转向 `兼容清理 + 内容补强 + 资源补图`

当前还应补充一个面向开发执行的口径：

- `项目已具备完整可玩闭环，但仍处于发布级体验收尾阶段`

## 2. 总体策略

坚持以下原则：

- 先固定结构，再补内容
- 先解决方向感，再补局部细节
- 先拆职责，再扩地图
- 让地图、剧情、资源、测试一起同步

## 3. 当前版本的核心工作线

### 工作线 A：地图重构

目标：

- 把世界结构稳定到 `北主线 / 东风险 / 西南预留`

### 工作线 B：飞船重构

目标：

- 把飞船变成真正可教学、可恢复、可制作、可引导的内部基地

### 工作线 C：引导与剧情连续性

目标：

- 让玩家始终知道“为什么现在去这个方向、出发前该准备什么”

### 工作线 D：工程拆分纪律

目标：

- 在地图扩展前先锁住模块边界，避免后面为了加内容又退回大文件堆功能

### 工作线 E：生存系统收尾

目标：

- 清理仍然残留在底层的 `stamina / pressure / poison` 兼容语义
- 但这条线当前属于配合地图重构的持续收尾，不再是唯一总主线

### 工作线 F：平衡性与经济护栏

目标：

- 让资源刷新、关键配方预算和战斗 TTK 进入可验证、可维护状态

## 4. 优先级路线图

### P0：文档与边界冻结

目标：

- 让团队可以直接按文档排期开发

交付：

- 目标设计文档
- 当前状态审计
- 地图重构执行单
- 近期执行清单

完成标准：

- 团队不需要重新翻旧文档，也能明确下一步做什么

当前状态：

- 已完成

### P1：地图骨架与飞船内部重构

目标：

- 先把最影响后续开发效率的空间结构固定下来

建议任务：

- 冻结地图总布局
- 重构飞船主通道与舱室
- 固定基地出口、北侧入口、东侧入口、西南边界

完成标准：

- 地图方向感稳定
- 飞船内部功能布局稳定

当前状态：

- 已完成第一轮核心落地

### P2：北侧主线区与东侧 swamp 节奏重排

目标：

- 让区域分工真正服务于主线推进和生存学习线

建议任务：

- 北侧迁移石碑、遗迹、Boss、Signal Tower
- 东侧重排外沼泽和深沼泽的风险层次
- 收紧 Rope / Camp / 防护服 / 补氧资源的价值曲线

完成标准：

- 北侧负责主线收束
- 东侧负责生存准备验证

当前状态：

- 已完成第一轮核心落地

### P3：引导链、资源和测试同步

目标：

- 让改造后的地图真正可玩、可读、可维护

建议任务：

- 更新通讯器提示和目标文本
- 同步地图 Overlay、日志、阶段提示
- 更新资源缺口文档
- 为新布局补 smoke 测试

完成标准：

- 地图改完后，提示、资源和测试不掉队

当前状态：

- 已完成第一轮同步

### P4：扩展预留区表达与扩展钩子

目标：

- 为西侧 / 南侧未来扩展打基础，但控制当前范围

建议任务：

- 西侧边界与失踪船员线暗示
- 南侧边界与地下设施线暗示
- 地图、剧情和远景中的扩展钩子
- 固定扩展地图与扩展剧情任务文档，避免未来真开做时只有区域草图没有任务链

完成标准：

- 玩家知道未来能去哪里
- 当前版本又不会被扩展区抢主线
- 后续如果进入扩展开发，已经有可直接引用的地图职责与任务骨架

当前状态：

- 已完成第一轮 reserve 表达

### P5：混合生存系统清理与持续拆分

目标：

- 在地图方向稳定后，继续清理遗留兼容语义

建议任务：

- 收敛 `pressure` 相关旧文案和旧校验
- 逐步减少 `stamina / pressure / poison` 在底层的残留职责
- 对地图扩展带来的新交互继续做模块切片

完成标准：

- 玩家体验、文案和底层规则尽量不再互相打架

当前状态：

- 当前主线工作

### P6：平衡性与经济调优护栏

目标：

- 在不推翻现有结构的前提下，为资源经济和战斗曲线建立显式护栏

建议任务：

- 固定关键资源预算
- 固定资源刷新语义和测试
- 固定 Boss 与中后期战斗的目标 TTK 带
- 固定和平路线与英雄路线的准备成本说明

完成标准：

- 调平衡时不再依赖零散记忆或临时感觉
- 文案、玩法和测试对关键预算的理解一致

当前状态：

- 需要单独推进

## 5. 建议的实际开发顺序

建议按下面顺序推进：

1. 结局后闭环与发布级可玩性收口
2. 剩余兼容字段和旧语义清理
3. 北侧终局路线反馈补强
4. 东侧 swamp 节奏微调
5. 飞船舱室职责和视觉区分补强
6. reserve 区钩子和可读性资源补图
7. 平衡性与经济护栏收口
8. 补测试与文档同步收口

## 6. 当前不建议排在前面的内容

以下内容现阶段不应排在前面：

- 直接做完整西侧剧情线
- 直接做完整南侧地下章节
- 大规模新怪物扩张
- 大量装饰性系统
- 与地图重构无关的大型玩法新系统

原因：

- 当前收益最大的工作不是继续堆新东西
- 而是把地图、飞船、剧情引导和工程边界整理到位
