#### 数据结构扩展

```c
typedef struct Player {
    // ...现有字段...
    bool isDowned;        // 濒死状态标志
    float downedTimer;    // 濒死倒计时 (10 秒)
} Player;
```

#### 核心函数实现
**文件**: `src/task_system.c`

**TryEnterDownedState()** - 进入濒死状态
```c
static void TryEnterDownedState(Player *player) {
    if (!player->isDowned && player->stamina <= 0.0f) {
        player->isDowned = true;
        player->downedTimer = 10.0f;  // 10 秒濒死时间
    }
}
```

**UpdateDownedState()** - 更新濒死倒计时
```c
static void UpdateDownedState(Player *player, float deltaTime) {
    if (player->isDowned) {
        player->downedTimer -= deltaTime;
        if (player->downedTimer <= 0.0f) {
            player->stamina = 0.0f;  // 真正死亡
        }
    }
}
```

### 3. 体力系统优化

#### 安全区恢复提升
**文件**: `src/task_system.c`

```c
if (Map_GetAreaAt(...) == MAP_AREA_BASE || 基地或营地) {
    player->safeRecoveryTimer += deltaTime;
    safeRecoveryAmount = tasks->oxygenRepairLevel >= 2 ? 3.0f : SAFE_RECOVERY_AMOUNT;
    while (player->safeRecoveryTimer >= SAFE_RECOVERY_INTERVAL) {
        Player_RecoverStamina(player, safeRecoveryAmount);
        player->safeRecoveryTimer -= SAFE_RECOVERY_INTERVAL;
    }
}
```

**恢复速率**:
- **氧气修复等级 2**: 3.0 体力/秒
- **基础恢复**: 2.0 体力/秒
- **安全区外**: 0.0 体力/秒（自然恢复）

## 🎮 游戏流程

### 濒死状态流程

```
体力归零
    ↓
进入濒死状态 (isDowned = true)
    ↓
10 秒倒计时开始
    ↓
玩家尝试自救
    ├─ 成功 (体力 > 0) → 退出濒死状态，继续游戏
    └─ 失败 (10 秒后) → 真正死亡，复活到基地
```

### 自救方式

| 按键 | 物品类型 | 效果 | 成功率 |
|------|----------|------|--------|
| **Z** | 食物组合 | 恢复体力 | 高 |
| **X** | 镇静物品 | 恢复体力 + 清除压力 | 高 |
| **无** | - | 等待 10 秒后死亡 | 0% |
