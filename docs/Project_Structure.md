# SpaceCraft Living 重构项目结构

## 目标结构

项目继续维持 `include/ + src/ + resources/ + docs/` 的扁平 C 项目结构，但逻辑边界将按“底层不动、内容重建”的方式重新划分。

## 模块职责

### `src/main.c`

- 保留应用入口
- 保留窗口初始化与主循环

### `src/game_manager.c`

- 负责游戏总状态切换
- 保留输入缓冲、移动更新、相机跟随
- 统筹各系统的更新顺序与界面开关

### `src/map.c`

- 维护 Tile 地图
- 定义区域、障碍、陷阱、交互点与区域解锁
- 保留 `Map_IsWalkable`、`Map_GridToWorld` 一类底层能力

### `src/player.c`

- 保留玩家格子坐标与移动相关状态
- 扩展体力、压力、氧气、死亡次数、装备、资源库存
- 管理资源消耗、恢复、临时增益与基础战斗属性

### `src/task_system.c`

- 从旧的线性任务系统升级为“主线阶段 + 洛希指引 + 世界交互”系统
- 管理阶段推进、剧情文案、交互处理、怪物状态、资源节点刷新、结局判定

### `src/ui_system.c`

- 重构 HUD
- 提供制作面板、通讯器、地图、帮助面板
- 展示阶段目标、生存指标、昼夜状态、事件提示

### `src/save_system.c`

- 保存与读取新的玩家、生存、阶段、资源和世界状态

### `src/assets.c`

- 只加载约定命名的可选图片
- 文件缺失时继续使用程序化回退绘制

### `src/audio_system.c`

- 只加载约定命名的可选音频
- 文件缺失时保持无报错静音运行

### `src/localization.c` / `include/localization.h`

- 提供新的中文文案、操作提示、阶段名称、怪物名称、资源名称和结局文本

## 目录约定

### `resources/images/`

- 未来补齐全部图片资源
- 当前仅以命名约定和清单文档为准

### `resources/audio/`

- 未来补齐全部音效与 BGM
- 当前仅以命名约定和清单文档为准

### `docs/`

- 保存开发摘要、结构设计和后续实现说明

## 本轮开发范围

本轮开发优先完成以下内容：

- 依文档重建主线阶段和区域地图
- 接入三指标生存系统
- 接入基础资源采集、制作与修复流程
- 接入洛希通讯器与帮助界面
- 接入基础敌人与终局逻辑
- 输出完整资源命名清单

以下内容采用轻量化版本先落地：

- 怪物 AI 为简单寻路/追击/攻击逻辑
- 随机事件采用轮换表而非复杂事件池
- 小型解谜与日志系统先做轻量版入口
- 美术与音频暂以命名和说明文档保留
