## 🚀 快速开始

### 构建游戏

```bash
# 安装依赖
brew install raylib

# 编译运行
make
./build/SpaceCraftLiving
```

### 操作说明

| 按键 | 功能 |
|------|------|
| WASD | 移动 |
| E | 交互 |
| Space | 攻击 |
| B | 背包 |
| Q | 制作 |
| N | 通讯器 |
| Esc | 暂停 |
