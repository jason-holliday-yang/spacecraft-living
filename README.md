# SpaceCraft Living

`SpaceCraft Living` 是一个基于 `C + raylib` 实现的 2D 俯视角生存解谜游戏。玩家在氧气倒计时内穿过受损飞船，逐步修复系统并撤离。

## 已实现内容

- `100 x 100` 飞船瓦片地图，包含苏醒舱、工程舱、医疗舱、仓库区、逃生舱五个阶段区域
- 单格移动与路径阻挡，采用严格网格坐标推进
- 生存资源系统：`体力` 与 `氧气`
- 环境危险区：火焰、电气故障、真空泄露
- 线性任务流程：拿扳手 -> 修复氧气主控台 -> 修复医疗终端 -> 取得逃生钥匙 -> 抵达逃生舱
- 两名固定 NPC，对话会提供任务提示并推动流程
- 三格装备栏 + 背包拖拽整理
- 本地设置与本地存档
- 成功撤离 / 氧气耗尽 两种结局
- 缺少外部美术或音频资源时，仍可使用内置 fallback 表现正常运行

## 玩法说明

- 游戏开始时，玩家从苏醒舱出发，初始氧气为 `600` 秒
- 需要先靠近工程主管获取维修扳手，之后才能修复工程舱主控台
- 修复工程舱后会补充部分氧气，并解锁医疗舱
- 修复医疗终端后，体力恢复速度提升，同时解锁仓库区
- 在仓库区取得逃生钥匙后，逃生舱区域开放
- 携带钥匙到达逃生舱即获胜；氧气降为 `0` 则失败

## 生存规则

- 移动和交互都会消耗体力
- 站在危险地块上会持续额外消耗氧气，并周期性扣减体力
- 体力过低时移动速度会变慢
- 在安全区域停留会缓慢恢复体力

## 操作

- `WASD` / `方向键`：移动
- `Space`：交互
- `B`：打开或关闭背包
- `M`：打开或关闭地图
- `Esc`：暂停 / 关闭当前菜单 / 结束界面退出

## 构建运行

```sh
make
./build/SpaceCraftLiving
```

默认 `raylib` 路径为 `/opt/homebrew`。如安装在其他目录，可执行：

```sh
make RAYLIB_PREFIX=/custom/prefix
```
